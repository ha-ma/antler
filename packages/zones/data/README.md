# packages/zones/data — 鹿ゾーンの元データと生成物

| ファイル               | 何か                                                                                                   | 手で直すか                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| `zones.waypoints.json` | ゾーンごとの始点・経由点・終点の座標と、その根拠（地名検索の検索語と返ってきた名称）、段階・出典・係数 | 直す（ここが元）                                         |
| `zones.source.json`    | `scripts/resolve-centerlines.ts` の出力（国道の中心線つき）                                            | 直さない                                                 |
| `zones.geojson`        | `npm run build:zones -w @antler/zones` の出力（PWA に同梱・A の API で配信）                           | 直さない（`build.test.ts` がバイト単位で一致を確かめる） |
| `cache/`               | 国土数値情報 道路データ（N13）のダウンロード先                                                         | リポジトリに入れない（`.gitignore` 済み）                |

## 作り直す手順

```sh
bash packages/zones/scripts/fetch-roads.sh          # 1. N13 を cache/ に取得（初回だけ。約 250 MB 展開後）
npm run resolve:zones -w @antler/zones              # 2. waypoints → zones.source.json
npm run build:zones -w @antler/zones                # 3. zones.source.json → zones.geojson
(cd packages && npx --no-install vitest run zones)  # 4. 一致と検証
```

`resolve:zones` はゾーンごとに「中心線の長さ」「始点・終点の直線距離」「その比」「各点から国道の線までの距離」を出す。
比が 2.5 を超える（別の国道に迷い込んだ疑い）・点が国道から遠すぎる（既定 400 m。点ごとに `maxSnapM` で広げたものは理由を `basis` に書く）・
同じ路線のゾーンが 500 m 以内に近づく（`build:zones` が失敗する条件）のどれかに当たると、`zones.source.json` を書かずに終わる。

## 道路中心線: 国土数値情報 道路データ（N13）令和 6 年度版

- ページ: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N13-2024.html （2026-11-03 に確認）
- 取得 URL: `https://nlftp.mlit.go.jp/ksj/gml/data/N13/N13-24/N13-24_<1次メッシュ>_GEOJSON.zip`
- 取得するメッシュ（`scripts/fetch-roads.sh`）。1 次メッシュ番号 = `floor(緯度 × 1.5)` と `floor(経度 − 100)` をつなげた 4 桁

  | メッシュ | 範囲（おおよそ）         | 使うゾーン                                                |
  | -------- | ------------------------ | --------------------------------------------------------- |
  | 6341     | 苫小牧・白老・登別       | R36 苫小牧〜登別、R36 空港南側                            |
  | 6441     | 札幌・定山渓・恵庭・千歳 | R230 定山渓、R36 えにわ、R36 空港                         |
  | 6542     | 芦別・富良野・旭川       | R38 滝里湖、R12 神居古潭                                  |
  | 6444     | 釧路・釧路町・厚岸・塘路 | R44 釧路町・厚岸・浜中、R240 阿寒IC、R272 別保、R391 塘路 |
  | 6445     | 浜中・根室               | R44 浜中・根室                                            |
  | 6544     | 阿寒・阿寒湖・別海       | R240 山間部、R241、R272 西春別                            |

- 形式: GeoJSON（JGD2011 経緯度）。属性に路線番号・キロポストは無い。`N13_003`（道路分類）が `1`（国道）の線だけを使う
  （`4` = 高速自動車国道等は使わない）。`N13_002`（種別）が `1`（通常部）以外と `N13_004`（道路状態）が `5`（建設中）は除く
- 位置の精度: 水平位置の標準偏差 25 m（データのページに記載）
- **利用条件（データのページの「このデータの使用許諾条件」）: オープンデータ（CC_BY_4.0）**。
  サイト全体の利用規約（https://nlftp.mlit.go.jp/ksj/other/agreement.html 、2026-03-23 施行）は PDL1.0 準拠で、
  出典の記載と、編集・加工した場合は「利用したコンテンツの名称と編集・加工を行ったこと」の記載を求める。加工した情報を国が作成したかのように公表してはいけない。
  原典は数値地図（国土基本情報）で、データのページに「測量法に基づく国土地理院長承認（複製）R 6JHf503」とある
- このリポジトリでの表記（各ゾーンの `sources` の末尾に入る）:
  「国土数値情報（道路データ N13）令和6年度版」（国土交通省）（上記ページの URL）をもとに EZO ROAD が作成（国道の中心線を区間の始点・終点の間でたどり、10 m で間引いて加工）
- **OpenStreetMap は使わない**（ODbL の共有義務を避けるため。仕様 R1）

## 区間の位置: 北海道開発局の地図（PDL1.0）

- 全道版「エゾシカ衝突事故マップ」令和 8 年度版: https://www.hkd.mlit.go.jp/ky/kn/dou_iji/splaat0000003n3x-att/splaat0000003n61.pdf
  （段階 `hkd-r8`。4 = 100 件以上（要注意区間）、3 = 50 件以上、2 = 10 件以上、1 = 1〜10 件未満。R3〜R7 累計、概ね 10 km 区間）
- 釧路開発建設部「エゾシカ注意報（釧路・根室地域版）」: https://www.hkd.mlit.go.jp/ks/douro_keikaku/qgmend0000002q0o-att/c86hsb0000002s50.pdf
  （段階 `kushiro-r3r7`。6 = 101 件以上 … 1 = 1〜20 件。R3〜R7 累計、概ね 5 km 区間）
- 利用条件: 北海道開発局サイトの「著作権について」（https://www.hkd.mlit.go.jp/ky/ki/kouhou/ud49g7000000omnw.html 、2026-11-03 に確認）。
  権利表記が無い限り PDL1.0 準拠。出典「北海道開発局ウェブサイト（URL）」と、加工した場合はその旨を記載。シンボルマーク・ロゴ・キャラクターは対象外。
  使うのは区間名と段階という事実情報だけで、地図の画像（下図は地理院地図の加工）や鹿のイラストは使わない
- 係数（`factors`）: 全道版 PDF の 2025 年の月別・時間帯別件数の図（図中の出典は北海道警察本部交通部交通企画課資料）を、最大 1 に正規化した値だけを置く。
  **件数の表そのものはリポジトリに書かない**

## 始点・終点の座標: 国土地理院の地名検索

- `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<地名>`（地理院地図の検索で使われているもの）で、地名・IC 名・橋やトンネルの名前を引き、
  返ってきた座標をそのまま `zones.waypoints.json` に置いた（検索語と返ってきた名称は各点の `basis`）。2026-11-03 に取得
- 点がどの国道に落ちたかは、地理院地図（標準地図）に国道の線と生成した中心線を重ねて目で確かめた（確認用の画像はリポジトリに入れていない）
- この API 自体の利用規約は確認できていない（報告書の「残る不安」）

## 範囲

初版のゾーンは北海道開発局の地図に名前が出ている国道の区間だけ。**道道・市町村道は調べていない**。ゾーン外（緑）は「安全」ではない。
