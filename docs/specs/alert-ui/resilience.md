# 障害耐性: alert-ui（共通スキーマと 3 状態アラート）

方針（ch6「B 誤検知」）: **誤検知を抑えるより見逃しを抑える。** 迷ったら danger 側に倒す。ただし危険側に倒すのは
「最後に deer:true を受けてから 5 秒」までで、それを過ぎたらゾーンの状態に戻す（ch6「B 可用性」の再接続 5 秒）。

## Failure Modes

| 失敗箇所     | 失敗内容                                   | 観測方法                         | システム動作                                                                    | ユーザー体験                     | 通知                                          |
| ------------ | ------------------------------------------ | -------------------------------- | ------------------------------------------------------------------------------- | -------------------------------- | --------------------------------------------- |
| フラグの受信 | JSON でない文字列                          | readAlertFlag が null            | 前の状態のまま                                                                  | 変化なし                         | logger.warn（`flag.invalid`、本文は入れない） |
| フラグの受信 | deer:true だが距離・方向が壊れている       | readAlertFlag が deer だけ読めた | danger を出す。距離「--」、矢印は前方                                           | 赤・ビープ・読み上げ（距離なし） | logger.warn（`flag.partial`）                 |
| フラグの受信 | 知らない版（v:2）                          | 厳しい検証が失敗                 | ゆるい読み取りで deer を読む                                                    | deer:true なら赤                 | logger.warn（`flag.version`）                 |
| WebSocket    | 切断・ハートビート停止（最後が deer:true） | 最後の受信から 5 秒              | 5 秒は danger のまま、過ぎたらゾーンの状態                                      | 赤のあと琥珀か緑（灰色帯は PWA） | PWA の feature で記録                         |
| WebSocket    | 切断（最後が deer:false）                  | 最後の受信から 5 秒              | フラグを古いものとして捨て、GPS のゾーンで表示                                  | 琥珀か緑                         | PWA の feature で記録                         |
| GPS          | 取れない（トンネル）                       | gpsZone が unknown               | 前のゾーンの状態を保つ                                                          | 変化なし                         | なし                                          |
| GPS          | 境界で出入りを繰り返す                     | 30 秒以内の再進入                | 状態は変わるがチャイムは鳴らさない                                              | 色と形は変わる、音は 1 回だけ    | なし                                          |
| 音           | 解除前（ユーザー操作の前）                 | canPlay=false                    | 何も鳴らさず、画面は出す                                                        | 画面だけ                         | なし（B-0 が案内する）                        |
| 音           | AudioContext の作成・再生に失敗            | 例外                             | 例外を外に出さず、canPlay=false に落とす。画面は止めない                        | 画面だけ                         | logger.error（`sound.failed`）                |
| 音           | wav の読み込みに失敗                       | fetch / decode の例外            | そのビープ・チャイムだけ飛ばし、次の周期で再試行しない（読み込みは起動時 1 回） | 音が欠ける                       | logger.error（`sound.load_failed`）           |
| 読み上げ     | speechSynthesis が無い・声が無い           | API が無い / 例外                | 読み上げだけ飛ばす。ビープは続ける                                              | ビープだけ                       | logger.warn（`tts.unavailable`）              |
| 時刻         | 端末の時計が飛ぶ（後ろへ戻る）             | now < receivedAt                 | 経過時間を 0 として扱う（danger を早く解かない）                                | 変化なし                         | なし                                          |
| 表示         | distance が NaN・負                        | 整形で検出                       | 「--」を出す                                                                    | 数値が「--」                     | なし                                          |

## Concurrency / Idempotency

| 対象                        | 並行実行されうるか             | 二重実行されうるか | 冪等性要件            | 実装方針                                                    |
| --------------------------- | ------------------------------ | ------------------ | --------------------- | ----------------------------------------------------------- |
| deriveAlertState            | 描画ごとに何度も呼ばれる       | 同じ入力で何度も   | **必須**（純粋関数）  | 入力だけで決まる。時刻は引数で受ける                        |
| AlertSoundController.update | 描画のたびに同じ状態で呼ばれる | 同じ状態の連続     | **必須**              | 状態の「変化」でだけ鳴らす。同じ状態の update は何もしない  |
| AlertSoundController.unlock | ボタンの連打                   | ありうる           | **必須**              | 2 回目以降は既存の AudioContext を使い回す                  |
| ビープの予約                | danger の出入りが短時間で続く  | 古い予約が残りうる | **必須**              | 状態が変わるたびに前の予約を必ず消してから予約し直す        |
| 読み上げ                    | danger → zone → danger の往復  | 2 回目の danger    | 1 回の danger に 1 回 | danger に入るたびに数え直す。前の発話は cancel してから話す |
