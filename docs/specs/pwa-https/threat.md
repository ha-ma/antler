# 脅威: pwa-https（車ごとの CA で PWA・wss・Capture を https にする）

この feature には入口が 3 つ増える・変わる: **pwa_server の https の口（8443、PWA の静的ファイル）**、**pwa_server の http の口（8080、設定ページと CA の配布）**、**AlertServer（8765）と CaptureServer（8767）の TLS**。どれも車内の Wi-Fi AP の中だけで待ち受ける（B3-1・ch6）。
守るものは 4 つ: **(1) CA と サーバーの秘密鍵を外に出さない**、**(2) CA が漏れても公開のサイトになりすませない**、**(3) AP の中のほかの端末が Mac mini になりすまして偽の 3 状態を出せない**、**(4) 静的配信から dist の外のファイルを読ませない・ページに他人の入力を入れない**。
ログイン・ロールは無いので、行は「何をしようとするか」を中心にし、拒否は検査の規則として書く。

**✅ (公開) の理由**: PWA の静的ファイルと CA の証明書は、車内の誰にでも配るためのもの。秘密を含まない（api の URL・トークンは入れない）。AP の WPA2（B3-1）が外との境界。

TLS で新たに守れるのは「AP の中のなりすまし」（AUTH-11）。いままでの ws では、AP に入れた端末が `ezoroad.local` に答えれば偽の赤・緑を出せた。

## IDOR / Mass Assignment チェック

### pwa_server（https・http）

- **クライアントから受け取るフィールド**: メソッド、パス（クエリは捨てる）、`Host`
- **サーバー側で決めるフィールド**: 返すファイル（起動時の一覧から）、Content-Type、キャッシュの見出し、設定ページに埋めるホスト（検査を通った Host のホスト名だけ）と CA の指紋
- **クライアントから受け取ってはいけないフィールド**: ディスクのパス、返す Content-Type、リダイレクト先
- **検証方法**: パスは一覧との完全一致（正規化してディスクを辿らない）。Host は Capture と同じ規則（`_host_allowed`）。本文は読まない
- **IDOR**: 資源を ID で指す口が無い

### AlertServer・CaptureServer の TLS

- 受け取るフィールド・検査は変えない（pwa-connect・edge-capture の threat.md が正）。足すのは TLS の層だけ

## 横断的セキュリティチェック

- [x] CORS: pwa_server は CORS ヘッダを付けない。Capture は今のまま（Host と同じホスト名のオリジンだけ）
- [x] レートリミット: pwa_server は同時 16（スレッドを作る前に数える）・受信ごとに 5 秒。CaptureServer は握手を枠の中で。AlertServer は握手 3 秒（`ssl_handshake_timeout`）
- 受け入れたリスク: 1 バイトずつ送り続ける接続は「受信ごとの 5 秒」では閉じない（合計の期限を持たない）。AlertServer の接続数の上限は握手と HTTP のあとに数えるので、握手の洪水は 3 秒ずつイベントループに RSA の計算を載せる。どちらも AP（WPA2）の中に入れた端末だけができ、平文のときから同じ。赤の経路の遅れが測れたら edge-latency で見直す
- 受け入れたリスク（2026-11-06 security-auditor W1・W3）: CA の配布と設定ページは http なので、同じ AP の端末が CA を差し替えうる（差し替えた CA は名前制約を持たない）。手順書でカードに CA の指紋を印刷し、ページの指紋と見比べさせ、パスフレーズを返却ごとに変える。名前制約は IP で効くので、AP のサブネットは家庭のルーターと重ならないもの（`10.73.x.1` など）を手順書で勧める。CA の有効期間（10 年）は鍵を車外に置く前提で据え置く
- [x] クリックジャッキング（security-auditor W4）: pwa_server の応答に `X-Frame-Options: DENY` とヘッダの CSP `frame-ancestors 'none'`（index.html の meta の CSP では効かないため）
- [x] 配布物の鍵（security-auditor W5）: dist に紛れた `.key`・`.pem`・`.p12`・`.pfx` は配らない
- [x] エラーメッセージ: 応答にパス・例外文を出さない（本文は空か短い固定の文）
- [x] ログマスキング: 上のとおり
- [x] TLS: TLS 1.2 以上、Python の既定の暗号スイート。HSTS は付けない（理由: 同じホストの http の設定ページ）
- [x] secrets: 鍵は git に入れない（`.gitignore` に `edge/detector/tls/`）。テストは一時ディレクトリに作る
- [x] 開発バイパス: 証明書の検証を外すフラグを作らない（テストのクライアントも CA を信頼して検証する）
