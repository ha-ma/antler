# 障害耐性: pwa-https（車ごとの CA で PWA・wss・Capture を https にする）

方針: **TLS の設定が壊れているときは起動を止める（平文に黙って戻らない）。動き出したあとの 1 本の接続の失敗は、その接続だけを閉じる。**
赤の経路（推論 → 判定 → 配信）に足すのは暗号化だけ。握手は接続のときだけで、握手の失敗・遅さは待ち受けと他の接続を止めない。
スマホの側の失敗（CA を信頼していない・証明書の期限・IP の変化）は、PWA の既存の「未接続」と再接続（pwa-connect R3・R6）に落ちる。

## Concurrency / Idempotency

| 対象                | 並行実行されうるか                                                 | 二重実行されうるか            | 冪等性要件                     | 実装方針                                                                                        |
| ------------------- | ------------------------------------------------------------------ | ----------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------- |
| pwa_server の配信   | 同時に複数の接続（スマホ 2 台・複数のファイル）                    | N/A: 読み出しだけ             | 不要（読み出しだけ）           | 起動時に作った一覧（変更しない辞書）を各スレッドが読むだけ。同時 16 をセマフォで数える          |
| `SSLContext` の共有 | AlertServer・CaptureServer・pwa_server の接続が同じ context を使う | N/A: 設定を読むのは起動時だけ | 不要                           | context は起動時に作り、あとで変えない（Python の `SSLContext` はスレッドから共有できる）       |
| `make_tls.py`       | 2 つの端末で同時に打つ                                             | 打ち直し                      | 必須（2 回目は CA を変えない） | 鍵は一時ファイルに書いて `os.replace`。CA があれば CA を作らない。`--new-ca` のときだけ作り直す |
| 設定ページの確認    | 1 つのページで 1 本ずつ                                            | 3 秒ごと                      | 不要（読み出し）               | 前の確認が終わってから次を始める                                                                |

## トランザクション境界

### 操作: `make_tls.py`（証明書の発行）

1. 引数を検査（私設の IPv4 だけ）。外れなら何も書かずに終了コード 2
2. 出力のディレクトリを 0700 で作る（あれば権限を 0700 に直す）
3. CA が無いか `--new-ca` なら: 一時ファイルに CA の鍵（0600）と証明書を作り、`os.replace` で `ca.key`・`ca.crt` にする
4. 一時ファイルにサーバーの鍵（0600）・CSR・証明書を作り、`openssl verify` で CA に対して検証してから `os.replace` で `server.key`・`server.crt` にする
5. 一時ファイルを消す。途中で失敗したら一時ファイルを消し、既存の `ca.*`・`server.*` は変えない

### 操作: pwa_server の起動

1. 設定を読む（`[tls]`・`[pwa_server]`）。TLS がそろわなければ終了コード 2
2. SSLContext を作る（壊れていれば終了コード 2）
3. dist を読む（64 MB まで。`index.html` 必須）。CA の証明書を読み、指紋を計算する
4. https の口と http の口を開く。どちらかが開けなければ、開いた方も閉じて終了コード 2
5. 停止（SIGINT・SIGTERM）で両方を閉じる
