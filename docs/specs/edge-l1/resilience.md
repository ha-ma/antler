# 障害耐性: edge-l1（L1 への問い合わせと fusion）

方針（ch6「B 誤検知」「B 可用性」、変更指示 §3.4）: **L1 はいつ壊れてもよい層。** 壊れたら L0 だけで動き、赤は鳴る。
L1 の失敗が「赤を下げる」向きに働く経路を作らない: 降格は、校正済みで新しい答えが条件をすべて満たすあいだだけで、失敗・古さ・不明は赤に戻す。

## Failure Modes

| 失敗箇所    | 失敗内容                                          | 観測方法                                        | システム動作                                                                     | ユーザー体験             | 通知                                                       |
| ----------- | ------------------------------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------ | ---------------------------------------------------------- |
| local-jev   | 起動していない・落ちた（接続を拒否）              | SDK の接続エラー                                | L0 だけで動く。降格中なら赤に戻す。失敗が続けば間隔を 2 秒まで延ばして聞き続ける | 赤は従来どおり           | logger.warning（`l1_unavailable`、`connect`、1 秒に 1 回） |
| local-jev   | 遅い（800 ms を超える）                           | `asyncio.timeout`                               | 打ち切る。降格中なら赤に戻す                                                     | 赤は従来どおり           | `l1_unavailable`（`timeout`）                              |
| local-jev   | 4xx・5xx（モデルが読めない 503 など）             | SDK の `TypeSafeAPIError`                       | リトライしない。L0 だけ                                                          | 赤は従来どおり           | `l1_unavailable`（`http`）                                 |
| local-jev   | 答えが壊れている（欠落・範囲外・NaN・選択肢不足） | 読み取りの検証                                  | 答え全体を捨てる。降格しない                                                     | 赤は従来どおり           | `l1_unavailable`（`bad_response`）                         |
| local-jev   | 別のモデルが答えた（重みの差し替え）              | 応答の `model` と `calibration.json` の `model` | 校正なしとして扱う（降格しない・`l1` を付けない）                                | 赤は従来どおり           | `l1.calibration_mismatch`（1 秒に 1 回）                   |
| 校正        | `calibration.json` が無い・壊れている             | 起動時の読み込み                                | 上書きを無効にする                                                               | 赤は従来どおり           | `l1.calibration_unavailable`（1 回）                       |
| SDK         | `typesafe-sdk` が入っていない                     | import の失敗                                   | L1 を動かさない                                                                  | 赤は従来どおり           | `l1_unavailable`（`sdk_missing`、1 回）                    |
| 設定        | 環境変数の接続先がループバックでない              | `start_l1` の検査                               | L1 を動かさない（車外へ送らない）                                                | 赤は従来どおり           | `l1_unavailable`（`remote_not_allowed`、1 回）             |
| L1 のタスク | 予期しない例外                                    | タスクの中の catch                              | タスクを止めない。次のティックへ                                                 | 赤は従来どおり           | `l1_unavailable`（`error`、型名だけ）                      |
| fusion      | 答えが古くなる（L1 が黙る）                       | tick ごとに答えの年齢（2.0 秒）を確かめる       | 降格を解いて赤に戻す                                                             | 赤に戻る                 | `flag.sent`（`reason=l1`）                                 |
| fusion      | 答えが 0.9 の前後で揺れる                         | 反転の時刻                                      | 赤に戻してから 1 秒は再び降格しない                                              | 入れ替わりは 1 Hz 以下   | なし                                                       |
| 入力        | カメラが止まった（stalled）あいだに答えが来る     | `judge.stalled`                                 | 何も送らない（edge-judge のまま）                                                | PWA は無受信で「未接続」 | 既存の `judge.stalled`                                     |
| YOLO と GPU | L1 の併走で L0 の fps が落ちる                    | 走行ログ（Step 6 で計測）                       | 問い合わせは同時 1 つ・2〜3 Hz・失敗時は間隔を延ばす                             | 赤の遅れ（未計測）       | Deferred（Mac mini 実機）                                  |

## Concurrency / Idempotency

| 対象                              | 並行実行されうるか                          | 二重実行されうるか             | 冪等性要件                     | 実装方針                                                                                |
| --------------------------------- | ------------------------------------------- | ------------------------------ | ------------------------------ | --------------------------------------------------------------------------------------- |
| L1 の問い合わせ                   | 検知（pump）と並んで動く                    | 前の答えを待たずに次を出しうる | **必須**（同時 1 つ）          | 1 本のタスクの中で await してから次。起こす（wake）のは Event で、重ねて送らない        |
| fusion の状態（答え・エピソード） | `on_result`・`tick`・`on_l1` が交互         | 同じ答えを 2 回当てうる        | **必須**（同じ答えで同じ出力） | すべてイベントループの上で同期に。答えは `(episode, track_id)` を持ち、古いものは捨てる |
| AlertFlag の再送                  | 降格・解除・ハートビート・L0 の変化が重なる | 同じ出力を 2 回送りうる        | **必須**                       | 出力の deer が変わったときだけ `reason=l1`。ハートビートは edge-judge のまま            |
| `start_l1` と pump の片付け       | 入力の終わりと L1 のタスク                  | N/A: 1 本                      | N/A: 1 本だけ                  | `pump` が `background` のタスクを作り、終わりに cancel して待つ                         |
