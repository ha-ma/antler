# 障害耐性: drive-tourism（A-3 運転中の観光の会話と、鹿ゾーンの前のおすすめ）

drive-audio-chat の `resilience.md` のまま（音と会話は運転を止めない。Claude・api が失敗したら見本の会話で走る）。ここには差分だけを書く。

## Failure Modes

| 失敗箇所           | 失敗内容                                                                               | 観測方法                                                              | システム動作                                                                               | ユーザーへの見え方                           |
| ------------------ | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | -------------------------------------------- |
| Claude API         | 楽しみの話で数字（「九時」「二時間」など）・鹿の語を書く（材料が増えて外れやすくなる） | `validateChatWriting` の理由のコード（digit・number-word・deer-word） | 1 回だけ作り直す。2 回とも外れたら 502・保存しない・10 分覚える（drive-audio-chat のまま） | 見本の会話（楽しみの話と写真つき。T9）で走る |
| 保存済みの束       | v1（`pleasure` の無い行）の束が残っている                                              | 鍵の版が違うので読まれない                                            | v2 の鍵で新しく作る（1 回 Claude を呼ぶ）                                                  | 楽しみの話の会話になる                       |
| sim の応答の確かめ | 古い api（`pleasure` を返さない）・マスターに無い id                                   | zod（任意・null 可）・`pleasureById`                                  | null として使う（写真なし）                                                                | 写真の無い会話で走る                         |
| 写真               | 記録の無い楽しみ・画像の読み込みの失敗                                                 | `photoOf` が null / `img` の error                                    | 記録が無ければ写真の面を出さない。読み込みの失敗は img の面だけ空く（文字は出る）          | 写真の無い吹き出し・カード                   |
| おすすめのカード   | その日にも到着地にも楽しみが無い                                                       | `recommendation()` が null                                            | 出さない                                                                                   | カードが出ない（会話と運転はそのまま）       |

## Concurrency / Idempotency

| 対象                            | 並行実行されうるか      | 二重実行されうるか                  | 冪等性要件                          | 実装方針                                                                                  |
| ------------------------------- | ----------------------- | ----------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------- |
| POST /api/trips/:id/day/:n/chat | drive-audio-chat のまま | drive-audio-chat のまま             | **必須**（drive-audio-chat のまま） | 鍵の材料の版を `chat:v2` に上げるだけ（single-flight・ON CONFLICT DO NOTHING はそのまま） |
| おすすめのカード                | N/A: 端末の表示だけ     | N/A: スナップショットから毎回決める | 不要                                | 純粋関数 `recommendation(scenario, snapshot)`                                             |

## トランザクション境界

### 操作: POST /api/trips/:id/day/:n/chat

drive-audio-chat のまま（1 行の INSERT。失敗しても何も残さない）。保存する JSON の行に `pleasure` が増えるだけで、表・列は変えない（`SCHEMA_VERSION` は据え置き）。
