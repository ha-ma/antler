## 概要

ユーザーがローカルで運転を試した 2 回目の指摘（2026-11-06、`docs/changes/2026-11-06-a-local-feedback-2-tourism.md`）のうち、観光の 2 つを運転画面（`apps/sim/src/features/drive/`）に入れる。

1. 運転中の会話を、A-1 で選んだ楽しみ（観光の中身）と、その写真が出てくる会話にする。置き場所は画面の右上
2. 鹿ゾーンに入る前に、次の楽しみのおすすめのカード（写真・一言・所要・到着の目安）を、会話とは別に画面の右下に出す

要件: ch3 A3-5（同乗者の吹き出し）・A3-7（つぎの楽しみ。赤の間は 60%）・A3-8（会話）、ch5（3 状態・4 言語・アクセシビリティ）、ch8（規約 1〜8）、付録 A #1（Claude の活用）。
前の feature: `docs/specs/drive-audio-chat/functional.md`（R10〜R19。この feature は R11 の話題・R13 の位置と行数・R15 の鍵の版・R16 の材料・R19 の見本の会話を変える）、`docs/specs/plan-trip-photos/functional.md`（写真と引用）。

**Tier 2 の理由**: 外部副作用（Claude に渡す材料とプロンプトが変わる）、永続化（保存する会話の束の行に `pleasure` が増える。表は変えない＝`trip_chats.deck` は JSON の列なので `SCHEMA_VERSION` は据え置き、保存の鍵の版を `chat:v2` に上げる）。認可と並行性は drive-audio-chat のまま（新しいルートなし）。

**範囲外**: 鹿の出方・ステージ（`domain/deer-*`・`stages` ほか）、路面・季節（`vehicle.ts`・`scene/`）は別のセッションが同時に直す。ここは `engine` のスナップショット（`zone`・`alert`・`stage`・`destination`）を読むだけ。立ち寄り（A-4）の組み込み、会話の読み上げ。

> 2026-11-06 main（drive-deer #46・drive-season #47）を取り込んだ。drive-season が会話のファイル（`chat/chat-deck.ts` の天気に `rain`、`chat/chat-ui.test.tsx` の当日の条件 v2）を変えたが、話題・写真・おすすめのカードのルール（R1〜R6）は変えていない。両方の変更を残した。

> 2026-11-06 performance（`docs/specs/performance/functional.md`）が `DrivePage.tsx`（3D のチャンクの読み込み口・開発用の fps の表示）と `engine.ts`（落ちたフレームを数える）を変えた。話題・写真・おすすめのカード（R1〜R6）は変えていない。

## Example Map

Story: 台湾から 4 人で初めての北海道を走るドライバーとして、運転中の車内の会話で今日の楽しみ（流氷・タンチョウ）の話を写真つきで聞き、鹿ゾーンに入る前には次の楽しみを思い出して、気持ちよく慎重に走りたい。

Questions は 2026-11-06 に推奨で決定（CLAUDE.md の方針）。決めたことは各 Rule に「推奨で決定」と書いた。spec-adversary の指摘（C1・M1〜M6・m1〜m7）の取り込みは下の「spec-adversary の指摘と決定」の表。

### 会話の話題を観光に（api の domain・application・プロンプト）

- T1 話題の割り当て（R11 の「話題」を置き換える。位置・話し手・行の数・id は R11 のまま）
  - 出発の行は `depart` のまま
  - 話の行（depart 以外）を移動・km の順に 0, 1, 2 … と数え、i mod 3 が 0 か 1 の行は、楽しみの候補（T2）があれば `pleasure`。i mod 3 が 2 の行と、候補の無い行は、`weather`・`light`・`scenery`・`snack`・`music` からシード付き乱数で選ぶ。話の行の 3 分の 2 が楽しみの話になる（推奨で決定）
  - R11 の「同じ話題を続けない」はゆるめる: 楽しみの行どうしは続いてよい（切り口 T3 で文を変える）。楽しみ以外の話題は、直前の楽しみ以外の話題と違うものにする（spec-adversary m1）。候補が 1 件の日は、楽しみの行がすべてその楽しみになる
- T2 楽しみの候補（その行の移動 L で決める。止まり場所は R11 と同じ「しおりの順を保ち、前には戻らない」）
  - 拠点がどの移動の始まりにも終わりにも無い楽しみは、止まり場所を「その日の最後の移動の後」にする（その日のどの移動でもこれから。spec-adversary M4。推奨で決定）
  - その日のこれからの楽しみ（止まり場所が L より後）があれば、それを順に回す（`timing: 'ahead'`）
  - その日のこれからの楽しみが無く、その日に済んだ楽しみ（止まり場所が L 以前）があれば、いちばん最近のもの（`timing: 'done'`）と、後の日の楽しみ（`timing: 'ahead'`）を順に回す
  - その日に楽しみが無ければ、後の日の楽しみ（しおりの日の順、最大 3 件。`timing: 'ahead'`）を順に回す
  - どれも無ければ候補なし（楽しみの話をしない）
  - 「順に回す」: 楽しみの行ごとに 1 つ進む（候補が 2 件なら A・B・A …）
- T3 切り口（同じ楽しみの話が続いても同じ文にならないように。推奨で決定）
  - `ahead` は、その楽しみの何回目の行かで `anticipation`（期待）→ `highlight`（見られるもの・できること）→ `tip`（楽しみ方のこつ・服装・寄り道の工夫）→ 繰り返し
  - `done` は `memory`（振り返り）
- T4 Claude に渡す材料（R16 に足す）: 楽しみの行に、楽しみの名前（4 言語）・拠点の地名（4 言語、マスター）・時間帯（`day` / `night` / `dawn`）・所要の区分（`short` 2 時間以下 / `half` 4 時間以下 / `long`）・`timing`・`angle`・`when`（`today` その日の楽しみ / `later` 後の日の楽しみ。spec-adversary M5）。楽しみの補足（note）と所要の時間の数は渡さない（時刻・数字・「鹿」を含むものがあるため）。プロンプトで `later` は「旅の後半に」の言い方にし、近い・今日・今夜とは書かせない
- T5 プロンプト: 楽しみの行では、その楽しみの中身（そこで見られるもの・できること・食べるもの・季節の様子）を具体的に、切り口に合わせて書く。北海道で広く知られた事実だけを使い、材料に無い施設名・店名・料金・時刻を作らない。`done` は「さっきの〜」の振り返り。ほかの決まり（R17 の長さ・数字・鹿の語・絵文字・言語）は同じ
- T6 応答と保存: `ChatLine` に `pleasure: string | null`（`pleasure` の話題の行は楽しみの id、ほかは null）を足す。保存の鍵の版を `chat:v2` に上げる（v1 の束は読まれない。行の形の違う束を返さない）。1 つの旅の束の上限 30 は v1 の束も数える（作り直しはまれなので許す。推奨で決定）
- T7 文の検証は R17 のまま（楽しみの名前に数字・鹿の語を含むものは無い。マスターのテストで守る）

### 会話の表示（sim の `chat/`）

- T8 写真つきの吹き出し（R13 を変える）
  - `pleasure` のある行は、一言の左に楽しみの写真（`apps/sim/public/photos/`、記録は `plan-trip` の `photoOf`。幅 64 px・高さ 48 px、`object-fit: cover`、飾りなので `alt=""`）と、一言の下に出典「写真: 撮影者 / ライセンス」（caption、`ink-muted`、4 言語の「写真」）を出す。写真の記録が無い楽しみは写真も出典も出さない
  - 出典はリンクにしない（HUD の会話は操作要素を置かない・ポインタを通す。R13）。出典のリンクは A-1 の楽しみのカードと `CREDITS.md` にある（推奨で決定）
  - 置き場所は画面の右上（右の列の上から積む。新しい行は下）。見える行は新しい 3 行まで（写真で 1 行が高くなるため。R13 の 4 行を変える）
  - 赤の間は待たせる・通知音なし・減光 60%・読み上げは最後の 1 行（R12・R13 のまま）
- T9 見本の会話（R19 を変える）: 話の行の話題を T1 と同じ数え方で割り当てる。楽しみの候補は、その日の楽しみ（`scenario.stops`）、無ければ到着地を拠点とする楽しみ（マスター。旅の月が `months` に入るもの（空は通年）だけ。spec-adversary M3。見本の場面（2 月の阿寒湖）は 2 件）。見本は済んだか・これからかを分けない（すべて「これから」の言い方）。文は 4 言語の決まった表に楽しみの名前を差し込む（同乗者 3 種・ラジオ 2 種。数字・鹿の語を含まない。名前は助詞・冠詞に左右されない位置に置く: ko は「〈名前〉에」「〈名前〉, …」、en は「Next up: 〈名前〉.」の形。spec-adversary M6）。行に楽しみの id を付けて、写真も出す
- T10 応答の確かめ（R18）: `pleasure` は任意・null 可（無ければ null として扱う）。楽しみのマスターに無い id は null にする（写真を出さない）

### ゾーンの前のおすすめ（sim の `components/hud/`）

- T11 出すとき（spec-adversary C1・M1 で決め直した。推奨で決定）: 1 つのステージに 1 回だけ、そのステージの始まりから、そのステージで最初にゾーンに入るまで出す
  - 出すのは、出発した後・走行中（`outcome: 'driving'`）・ゾーンの外・赤でない・ステージの帯（`STAGE_BANNER_MS` = 2 秒）が消えた後。最初のステージは帯が無いので走り始めから
  - そのステージでゾーンに入った（`zone.gps.status` が `inside`）か赤になったら消し、同じステージの中ではもう出さない（まとめたステージのゾーンの合間・赤の後に出し直さない）。次のステージに移ったら、また出す
  - 走行が終わったら消す。ゾーンの無い日は出さない（ステージが無い）。アラート OFF の走行でも出す（ゾーンの表示は OFF でも残るため）
  - 距離（5 km）では決めない（ステージは入口の 5 km 手前から始まるので、距離で決めるとステージの中でゾーンの外ならいつも成り立つ）
- T12 出す楽しみ（spec-adversary M2・M3）: 今の位置より先にあるその日の楽しみのうち、いちばん近いもの。楽しみの位置は、拠点の地点（マスターの緯度経度）にいちばん近い移動の区切り（ルートの始点・各移動の始まり・終点）の道のり。どの区切りからも 15 km より遠い拠点は終点に置く（その日の最後まで「先」）。先に残っていなければ、到着地（`scenario.to`）を拠点とする楽しみ（旅の月が `months` に入るもの）を、ステージの番号で順に回す（その日の楽しみは除く）。どれも無ければ出さない
- T13 中身: 見出し「この先のおすすめ」（eyebrow）、写真（幅いっぱい・高さ 112 px、`object-fit: cover`、`alt=""`。記録が無ければ写真の面を出さない）、楽しみの名前（heading）、一言（note。ただし note に鹿の語（鹿・シカ・deer・사슴。NFKC・大文字小文字を区別しない）が入るときは出さない。偽警報に見える文を出さない）、所要の目安（ja「所要 約 n 時間」・en「About n h」・zh「約 n 小時」・ko「약 n시간」、数は等幅）、到着地の時刻（楽しみの拠点がその日の到着地のときだけ。ラベルは「到着地」で、目的地の到着予定 `destination.etaMs` の JST の時刻。楽しみの時刻に読ませない。spec-adversary m7）、出典（T8 と同じ平文。長い撮影者名は折り返す）。文言は旅の言語（4 言語）
- T14 見た目と配置: 右の列の下、音量の操作（`AudioControls`）の上に置く（推奨で決定。右上の会話・右下のおすすめ・いちばん下に音量の操作）。高さが足りないとき（画面の高さ 760 px 以下）はカードの写真を出さない。それでも足りなければ会話の古い行が上に隠れる（会話の列は下を揃えずに上から積み、はみ出しは切る。spec-adversary m2）。幅は右の列（`--drive-chat-w`）。`surface` の面・`line` の枠・`radius-l`。色・文字・余白は tokens.json の CSS 変数だけ。現れるときは 0.2 秒で下からふわっと（点滅しない。`prefers-reduced-motion` では動かさない）。操作要素を置かない・フォーカスを取らない・ポインタを通す。`<aside>` に `aria-label`（4 言語）。読み上げの領域（aria-live）にしない（アラートの読み上げと重ねない）
- T15 アイコン: 使わない（写真と文字だけ。要るならインライン SVG）。絵文字を使わない

## ユースケース

### UC-1: 楽しみの話題を割り当てる（T1〜T3・T6）

- **Given**: 保存した旅とその日の DayPlan
- **When**: 会話の束を組み立てる
- **Then**: 話の行の 3 分の 2 が楽しみの話。楽しみの id・時（ahead / done）・切り口が決まる
- **Examples**: ペルソナの D1（流氷・タンチョウ）→ 楽しみの行はその 2 件を回す / 楽しみの無い日で後の日に 2 件 → その 2 件を ahead で回す / 旅に楽しみが 1 件も無い → 楽しみの行なし、話題は R11 の 5 種 / 同じ楽しみの 1・2・3・4 回目 → anticipation・highlight・tip・anticipation / 最後の楽しみを過ぎた移動 → memory と後の日の楽しみ

### UC-2: Claude の材料とプロンプト（T4・T5）

- **Examples**: 楽しみの行の材料に名前・拠点・時間帯・所要の区分・timing・angle がある / note・時間の数・時刻・距離は無い / プロンプトに切り口の書き分けがある

### UC-3: 写真つきの会話（T8〜T10）

- **Examples**: api の楽しみの行 → 吹き出しに写真と「写真: kkawamura / CC BY 4.0」（リンクなし）/ 天気の行 → 写真なし / 4 行目 → いちばん古い行が消える / 見本の場面 → 阿寒湖の楽しみの行が出て写真つき / `pleasure` の無い応答 → 写真なしで使う / マスターに無い id → 写真なし

### UC-4: ゾーンの前のおすすめ（T11〜T15）

- **Examples**: ステージ 1 の始まり → 出る / ステージ 2 に移った直後（帯の 2 秒）→ 出ない、帯が消えたら出る / ゾーンに入る → 消える / ゾーンを出て同じステージの次の入口の前 → 出ない / 赤 → 消え、赤が終わっても出ない / 完走 → 消える / 最初の楽しみの拠点を過ぎた → 次の楽しみ / その日の楽しみをすべて過ぎた・楽しみの無い見本の場面 → 到着地（阿寒湖）の楽しみ / 7 月の旅で到着地の楽しみが冬だけ → 出さない / 拠点が到着地 → 「到着地」の時刻、そうでない → 時刻なし / 野付半島（note に「鹿」）→ 一言を出さない / en の旅 → 英語の見出しと名前
