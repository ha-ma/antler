# 仕様: drive-tune（運転のステージ・必ず出る鹿・実測に合わせたブレーキ・区間の案内・ミラーとダッシュボード）

## 概要

**drive-season（2026-11-06）での変更**: R3 の μ をそのまま使い、新しい路面の決め方で雨（濡れ）・雪（圧雪・凍結）の日が乾燥より止まりにくいことを、場面→エンジン→停止距離のテストで固定した（`docs/specs/drive-season/functional.md`）。

**drive-audio-chat（2026-11-06）での利用**: `DriveEngine.telemetry()`（R6）を運転の音の合図に、HUD の右の列（`--drive-chat-w`）を車内の会話と音量の操作に使った（仕様は `docs/specs/drive-audio-chat/`）。会話はステージを移って道のりが飛ぶとき、飛ばした区間の行を最後の 1 行だけ出す（drive-audio-chat R12）。drive-tune の振る舞いは変えていない（`use-keyboard-drive.ts` に入力欄の扱いを足しただけ）。

ユーザーがローカルで運転を試した指摘（`docs/changes/2026-11-06-a-local-feedback.md`）を、運転（`apps/sim/src/features/drive/`）に入れる。
要件: ch3 A3-1（運転席・メーター）・A3-4（車両力学。制動距離の数値はこの指摘で置き換える）・A3-5（HUD）・A3-6（タイムラプス）・A5-2（鹿の出現）・A5-6（完走）、ch6「A 性能」。
前の feature: docs/specs/drive-3d/functional.md（R1〜R13）、docs/specs/drive-link/functional.md（R1〜R8）。ここで変わるルールはそれぞれの仕様にも書き直す。

**Tier 1**: 認可・永続化・外部への副作用・並行性に触れない。

**範囲外**: 音そのもの（エンジン・ブレーキ・BGM・会話の通知音）と車内の会話の表示（drive-audio-chat。`drive/audio/`・`drive/chat/`。この feature は合図を出すだけ）、立ち寄り（A-4）の組み込み（drive-link の Deferred のまま）、スマホ操作（mobile-landscape）。

## Example Map

Story: 北海道を走る旅行者として、鹿の出る区間に集中して、本物に近いブレーキの効きで鹿を避ける練習をしたい。いまどこを走っていて、何が楽しみなのかも見ながら。

- R1: 走る区間は「ステージ」（指摘 1）
  - その日のルートの鹿ゾーンの区間ごとに、入口の 5 km 手前（ルートの始点より前にはしない）から出口までを 1 つのステージにする。前の出口から次の 5 km 手前までが 0 以下ならまとめる
  - 運転は最初のステージの始まりから始める。始まりの時計は、しおりのその移動の出発時刻に、移動の平均の速さ（距離 ÷ 所要）で始まりまで走った時間を足した時刻（見本の場面は 50 km/h）
  - ステージの出口（最後の区間の出口）を越えたらそのステージをクリア: 鹿モードを解く（フラグを解除して safe、鹿を消す）。次のステージがあれば、その始まりへ移る（時計は平均の速さで間の道のりを走った時刻へ。ただし今の時計より前には戻さない）
  - 最後のステージをクリアしたら、その日の旅程をクリア（`completed`）
  - ゾーンの無い日は、出発の案内に「この日は鹿ゾーンを通りません」。「出発」ですぐにクリア（`completed`、ゾーン通過 0）
  - ステージの移動は再生速度を 1× にし、一時停止は解かない。速さは保ち、左車線の中央に戻す。移った**あと**に「ステージ n / m クリア」の帯を 2 秒（シミュレーションの時計）出す（その間も走れる）
  - クリアの合図の順: 赤の最中なら `alert-release` → `stage-clear`（→ 最後なら `completed`）。音を鳴らす側のビープを止めるため
  - クリアのときに、後ろに過ぎた鹿は回避（avoided）。まだ前にいる鹿は消すが、遭遇の記録は pending のまま残す（A-7 の回避率を水増ししない）
  - ステージを移るたびに、アラートの音のコントローラを同じ出力先（解除済み）で作り直す。手前が 5 km しかないので 16× では alert-ui の `ZONE_REARM_MS`（30 秒、壁時計）より早く次のゾーンに入り、チャイムが抑えられるため（drive-3d R4 の「ゾーンの間は実時間 30 秒を超える」はこれに置き換える）
  - 最初のステージの始まりがルートの始点より前になるときは始点から（見本の場面は手前を 5 km にしたが、入口は線から 150 m の帯に入る所なので約 140 m 足りず、始点に丸まる）
- R2: 鹿は区間ごとに最低 3 頭・最大 100 頭（指摘 2）
  - 区間の候補のうち道のりの順に先頭から、群れの頭数を合わせて 3 頭に届くまでを「必ず出る」にする。残りは今までどおり危険度で出るか決める
  - 「遭遇」は鹿が車から見える道の近くに現れること（赤が出るかはカメラの捕捉とアラートの ON/OFF しだい）。必ず出る候補が「林縁で目の反射だけ」（林に隠れて道に出ない）なら横断に替える
  - 区間で出した頭数が 100 頭に届いたら、その区間ではもう出さない（群れが 100 頭を越えるなら出さない）
  - 区間が短くて候補が 3 つ作れないときは、候補の間隔を区間の長さの 3 等分にする
  - 同じ旅・同じ日（同じ種）なら同じ鹿
- R3: ブレーキは実測に合わせる（指摘 3。数値と出典は変更記録の §2.3）
  - 減速度 = μ(v) × g（g = 9.81）。μ は 乾燥 0.8・湿潤 0.57・圧雪 0.36・凍結 0.08
  - μ(v) = μ × clamp(1 − 0.0015 ×（v − 40 km/h）, 0.85, 1.05)（速いほど効きが弱い）
  - ブレーキを踏んでから 0.15 秒で減速度が立ち上がる（直線）。離したら 0 に戻る
  - ABS: 湿潤・圧雪・凍結で、10 km/h 以上でブレーキ（S を含む）を踏んでいる間は働く（タイヤがロックしないのでハンドルが効く）。ダッシュボードに「ABS 作動」の表示（実車の ABS 警告灯は故障の表示なので、それとは別の作動表示として出す）。乾燥では働かない（効きの余裕がある）
  - 摩擦円: ブレーキに使っているぶん、横に動く（ステア・車線への吸着）のに使える摩擦が減る（踏みきりで半分）。凍結で踏みながら大きく避けることはできない
  - S（走っている間の減速）はブレーキの 6 割の減速度
  - 制動距離の目安（テストで固定。踏んだ瞬間から 0.5 km/h 未満になるまでの距離。立ち上がりの 0.15 秒を含む）: 40 km/h から 乾燥 約 8 m（μ = 0.8 から計算。乾燥の実測は 60 km/h の 17.7 m）・湿潤 約 11 m・圧雪 約 17 m・凍結 約 79 m（実測 ±10%）。60 km/h 乾燥で 18〜21 m
  - drive-3d R3 の「60 km/h から乾燥で 50 m・×1.3 / ×1.5 / ×2.0」は廃止
- R4: いまの区間の案内（指摘 4）
  - HUD の左側（ゾーン状態の下）に、その日の区間（D の番号・出発地 → 到着地）、目的地までの残り km と到着予定（JST）、ステージ（n / 全 m）、その日の楽しみ（しおりで確定した立ち寄りの楽しみの名前と一言、楽しみのマスター）
  - 目的地はその日のルートの終点。到着予定は、いまの時計に、しおりの移動の平均の速さで終点まで走った時間を足した時刻（いまの速さは使わない。止まっても予定が飛ばない）
  - 楽しみが無い日は区間と残りだけ。見本の場面は区間（釧路 → 阿寒湖）とステージだけ
  - HUD の右側は会話の表示のために空ける（速さと音のトグルは左下とダッシュボードへ）
- R5: バックミラーとダッシュボード（指摘 5）
  - バックミラーに後方の映像（別のカメラ。15 fps 程度、解像度は抑える。PC 60 fps を崩さない）
  - ダッシュボード: 速度計・回転計・ギア（D と段）・時計（JST）・外気温・ABS の灯・ナビの次の案内（「n km 先 鹿ゾーン」「鹿ゾーン 残り n km」「目的地まで n km」）
  - 回転数とギア: 6 速のオートマ。速さとアクセルから決める（停止 750 rpm・1 速、2,500 rpm でシフトアップ（1→2 速 22.5 km/h … 5→6 速 97.5 km/h）、1,200 rpm を下回るとシフトダウン、アクセルを踏むと 8% 高め、表示の上限 3,000 rpm、後退は R）
  - 外気温: 月と光の区分から決める表（道東・釧路の月ごとの日最高・日最低の目安を昼・夜に当てる。2 月の昼 −4 °C、夜 −14 °C、薄暮・夜明けはその間）。路面と合わない組み合わせ（夜 −14 °C で湿潤など）もそのまま出す（当日の条件は brief-map の表が正）
- R6: 音の合図の差し込み口（drive-audio-chat 用）
  - エンジンが合図を出す: ゾーンの出入り・鹿の出現・赤の始まりと解除・ステージのクリア・旅程のクリア・衝突
  - 毎フレームの値: 回転数・アクセル（0/1）・ブレーキの強さ（0〜1、立ち上がりを含む）・速さ・ABS
  - drive-tune は音を鳴らさない（ブラウザの自動確認でも鳴らない）

  - ゾーンの無い日の結果は、遭遇 0・入力の列が空・フレームの要約が null の `completed`（DriveRoute がそのまま A-7 に記録する）

推奨で決定（CLAUDE.md の方針。PR にも書く）: 変更記録 §2 のすべて。spec-adversary の指摘（C1・M1〜M7・m1〜m5、2026-11-06）は上の各ルールに取り込んだ。

## ユースケース

### UC-1: ステージ（R1）

- **Given**: その日のルートとゾーンの区間
- **When**: 運転の場面を作り、走る
- **Then**: 最初のステージの 5 km 手前から始まり、出口でクリアし、次のステージへ移り、最後でその日をクリアする

### UC-2: 鹿（R2）

- **Given**: 区間の候補と種
- **When**: 候補を作り、車が近づく
- **Then**: 区間ごとに 3 頭以上 100 頭以下の鹿が出る

### UC-3: ブレーキ（R3）

- **Given**: 路面と速さ
- **When**: ブレーキを踏む
- **Then**: 実測に近い距離で止まり、速いほど効きが弱く、滑りやすい路面で ABS が働く

### UC-4: 区間の案内とダッシュボード（R4・R5）

- **Given**: 旅程とシミュレーションの状態
- **When**: 画面を描く
- **Then**: 左に区間の案内、ダッシュボードに速度・回転・ギア・時計・気温・ABS・ナビ、ミラーに後方

### UC-5: 音の合図（R6）

- **Given**: 走行中の出来事
- **When**: エンジンが進む
- **Then**: 購読した側に合図と毎フレームの値が届く
