# 障害耐性: pwa-uplink（PWA → edge の速度・ゾーン・光）

方針: **`vehicle` が無くても、壊れていても、古くても、今までの動き（固定値の L1 と L0 の赤）に戻る。** `vehicle` の失敗が赤の経路・ack・再接続に波及しない。

## Failure Modes

| 失敗箇所    | 失敗内容                                                         | 観測方法                                                  | システム動作                                                                                                                                                           | ユーザー体験                                   | 通知                                                                       |
| ----------- | ---------------------------------------------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| PWA の GPS  | 許可なし・測位が来ない・5 秒より古い・端末の時計が戻って経過が負 | `useGpsZone` の判定・測位の時刻                           | 3 項目とも無し → `vehicle` を送らない（ほかの端末の実値を消さない）。edge は期限で固定値                                                                               | 変化なし（琥珀のまま。位置の案内は pwa-drive） | なし（pwa-drive の `gps.error` のみ）                                      |
| PWA の GPS  | `speed` が `null`・NaN・負（止まっているとき・端末による）       | `Number.isFinite` と 0 以上                               | 速度の項目だけ送らない（負を 0=停止にしない）。ゾーン・光は送る                                                                                                        | 変化なし                                       | なし                                                                       |
| PWA の送信  | socket が open でない（再接続中）                                | `EdgeSnapshot.status`                                     | 送らない。溜めない。再接続後の次の更新で送る                                                                                                                           | 「未接続」帯（pwa-connect）                    | なし（頻繁なのでログに出さない）                                           |
| PWA の送信  | `send` が例外（閉じかけ）                                        | try/catch                                                 | その 1 通を捨てる。ack・描画・再接続は止めない                                                                                                                         | 変化なし                                       | logger.warn（`vehicle.skipped`、理由だけ）                                 |
| PWA の送信  | 検証に通らない値（NaN など）                                     | `ClientMessageSchema`                                     | 送らない（項目を落とした形では送り直さない）                                                                                                                           | 変化なし                                       | logger.warn（`vehicle.skipped`、理由だけ）                                 |
| PWA の送信  | StrictMode の二重の effect・再描画                               | 最後に送った時刻                                          | 0.9 秒以内は送らない                                                                                                                                                   | 変化なし                                       | なし                                                                       |
| edge の受信 | 壊れた JSON・知らない型・64 KB 超                                | 受信時の検証（edge-judge）                                | 無視（超過は切断）。`vehicle` の状態は変えない                                                                                                                         | 変化なし                                       | logger.warn（`client.ignored`、型名だけ）                                  |
| edge の受信 | `vehicle` が検証に通らない（範囲外・NaN・余分な項目）            | pydantic の検証                                           | 捨てる。前の値を残す（新しさは進めない）                                                                                                                               | 変化なし                                       | logger.warn（`vehicle.invalid`、1 秒に 1 回まで・本文なし）                |
| edge の受信 | 洪水（1 秒 5 通超）                                              | 接続ごとのカウント（edge-judge）                          | 超過を捨てる。赤の送信は止めない                                                                                                                                       | 変化なし                                       | logger.warn（`client.throttled`）                                          |
| edge の保持 | 保持・検証で想定外の例外                                         | `on_client_message` の try/except                         | 握りつぶさず `vehicle.error`（型名だけ）を残し、前の値を残す。接続は落とさない                                                                                         | 変化なし                                       | logger.error（`vehicle.error`、型名だけ）                                  |
| edge の鮮度 | PWA が止まる・Wi-Fi が切れる・端末の時計が狂う                   | 受け取った時刻（単調時計）との差                          | 速度は 3 秒、ゾーンと光は 10 秒たったら固定値へ。端末の時刻は見ない                                                                                                    | 変化なし（L1 は今までの固定値）                | logger.info（`vehicle.stale`、読んだとき 1 回）                            |
| edge の鮮度 | 時計が後ろへ戻る                                                 | now < received_at                                         | 経過 0 として扱う（新しい扱い）。例外にしない                                                                                                                          | 変化なし                                       | なし                                                                       |
| L1 の入力   | 実値が校正のときの分布と違う（昼・低速・ゾーン外）               | `calibration.json` の `context`・`l1.result.state_source` | 校正が `fixed`（既定）なら実値を使わず固定値。`real` か校正なしのときだけ実値。速度は 30 km/h で持ち上げ。降格の条件は変えない。疑わしければ `vehicle_state = "fixed"` | 変化なし                                       | logger.info（`l1.vehicle_ignored` を 1 回、`l1.result` の `state_source`） |
| edge の設定 | `vehicle_state` / `vehicle_max_age_s` が不正                     | 起動時の検証                                              | `ConfigError`（キー名つき）で起動しない                                                                                                                                | 起動しない                                     | 起動時のエラー                                                             |

## Concurrency / Idempotency

| 対象                                    | 並行実行されうるか                                    | 二重実行されうるか     | 冪等性要件                                 | 実装方針                                                                                                          |
| --------------------------------------- | ----------------------------------------------------- | ---------------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| edge の `VehicleReport` の置き換え      | 複数の接続から交互に届く                              | 同じメッセージが何度も | **必須**（同じメッセージで同じ状態）       | イベントループの上だけで触る。1 件を丸ごと置き換える（部分更新しない）。最後に届いた有効なものが勝つ              |
| edge の読み取り（問い合わせの組み立て） | L1 のタスクと受信が交互                               | N/A: 読むだけ          | **必須**（読み取りが保持した値を変えない） | `vehicle_report(max_age)` は hub 自身の単調時計で古さを決める。変えるのは `vehicle.stale` を 1 回出すための印だけ |
| PWA の送信                              | 1 秒の更新・再描画・StrictMode の二重 effect が重なる | ありうる               | **必須**（1 秒に 1 通）                    | 最後に送った時刻を ref に持ち、0.9 秒以内は送らない                                                               |
| PWA の再接続                            | 切断と更新が同時                                      | 古い socket への送信   | **必須**（古い socket に送らない）         | 現在の socket が open のときだけ送る（`EdgeClient` の `socket`・`status`）                                        |
