# 仕様: dataset-footage（自分で撮った映像の受け取り: SHA-256 → 焼き込みの塗りつぶし・顔とナンバーのぼかし → 匿名化したフレームと manifest → 区間 → 走行単位の分割）

## 概要

外部の研究の引継ぎメモ（`~/work/antler-yolo-mac/docs/HANDOFF_TO_ANTLER_2026-11-06.md`）の §5・0 節の順 2。
ユーザーが自分のドライブレコーダーで撮った映像を、**位置と他人の情報を消したフレーム**にして `dataset/private/self-footage/` に置き、次の 2 つの feature が使える形にする:

- `dataset-synth`（順 3）: 鹿のいない区間のフレームを、3D の鹿を合成する背景に使う
- `dataset-train` の更新（順 4）: 鹿のいる区間のフレームにラベルを付けて実写の鹿として学習・評価に、鹿のいない区間を誤検出の評価に使う

`dataset/self_footage.py` の `ingest` が、`dataset/self_footage.toml`（クリップ・走行・カメラの一覧。Git に入る）に書いたクリップを 1 本ずつ処理する:

1. 元の映像の SHA-256 を計り、一覧の値と、ユーザーが置いた `<file>.sha256` の両方と照合する
2. 一覧の区間と間引きの間隔から、書き出すフレームを決める
3. フレームごとに、焼き込み（日時・速度・GPS）の矩形を黒で塗りつぶし、人の箱と車の箱の下半分をモザイクにし、EXIF の無い JPEG で書く
4. 塗りつぶした後のフレームに、焼き込みの残り（動かない明るい文字）が無いことを数値で確かめる
5. `manifest.json` に、クリップ・走行・分割・区間・フレームごとの用途と SHA-256 を書く

**今回（1 回目、2026-11-06）の 5 本**: すべてドライブレコーダー（1920×1080、27.5 fps、約 3 分、道東）。鹿あり 2 本（夜）・鹿なし 3 本（夜 2・朝 1）。2 回目（2026-11-07 の夜）は、一覧に行を足して同じ `ingest` を回すだけで追加できる。

要件: ch5-common.md「データ収集と同意」（保存しない: 精密な位置・端末識別子・車内を写す映像）、ch6-nfr.md「プライバシー」「ライセンス」（自作は可）、ch4-edge.md B2（L0 = YOLO、`deer` クラス）。
根拠になった判断: 引継ぎメモ §1（ユーザーが自分で撮った背景は学習に使え、配ることもできる。ただし他人の顔・ナンバーは ch6 の決まりに従う）、§5（受け取りの手順）。ch5・ch6 の本文は顔・ナンバーを名指ししていない。ぼかしの根拠はメモ §5 と ch5「保存しない」の趣旨（第三者を識別できる情報を残さない）。
既存: `docs/specs/dataset-train`（YOLO のラベルの形・素材の manifest の `files[]`・走行 / 動画単位で分ける決まり）、`dataset/README.md`・`dataset/PRIVATE-DATA.md`（置き場所と用途）。

**範囲外**（別 feature・別の判断）:

- 鹿の箱のラベル付け（方法は Questions で決めた。道具とラベルそのものは後続）
- 3D の鹿の合成（`dataset-synth`）、学習と評価（`dataset-train` の更新。`train_sources.toml` への登録と、`license = "self"` の YOLO の素材を `train_l0.py` が受けるようにする変更も含む）
- 匿名化したフレームの公開・配布（ぼかしを人が確かめるまでしない。`blur_reviewed: false`）
- B の車載カメラ・スマホの映像（カメラを一覧に足せば同じ手順で入るが、今回は届いていない）

**Tier 1 の根拠**: 認可・永続化スキーマ（DB・API）・外部への送信・並行性を足さない。書くのは gitignore 済みの `dataset/private/self-footage/` だけ。元の映像は読むだけ（変更しない）。検出器の重み（COCO の `yolo26n.pt`）は手元にあるものを読み、ダウンロードしない。

## 依存

- 新しい依存は足さない。一覧の検証・区間・分割・塗りつぶし・モザイク・焼き込みの残りの検査・JPEG のメタデータの検査・manifest は標準ライブラリと `numpy` だけで動く（CI は `edge/detector[dev]` だけで、opencv・ultralytics が無い）
- 映像の読み出し（opencv）・JPEG の書き込み（opencv）・人と車の検出（ultralytics の COCO の `yolo26n.pt`）は extra `day0` の環境だけにある。これらは差し替えられる薄い関数にし、テストは偽物を渡す（`train_l0.py` と同じ。実物はカバレッジから外す）
- 実データは `python -I dataset/self_footage.py ingest --raw <絶対パス> --out <絶対パス>` で回す

## Example Map

Story: B の開発者として、自分で撮った映像を、位置も他人の顔・ナンバーも残らないフレームにして、合成の背景と実写の鹿のラベル付けにすぐ使いたい。同じ走行のフレームが学習とテストに混ざる事故と、焼き込みの GPS が残る事故は、人の注意ではなく道具が止める。

- R1: 一覧（`dataset/self_footage.toml`。Git に入る＝公開の場所）
  - `[camera.<id>]`: `kind`（`dashcam` / `phone` / `vehicle`）・`facing`（`front` だけ。ch5「車内を写す映像は保存しない」。後ろ向き・車内のカメラは受けない）・`size`（[幅, 高さ]）・`overlay_masks`（焼き込みを塗る矩形 `[x, y, w, h]` px の配列。無ければ空）・`overlay_min_pixels`（陽性対照: 塗る前の矩形の中に見つかるはずの焼き込みの画素数。矩形があれば正、無ければ 0）。矩形は画面の中で、幅・高さが正
  - `[[drive]]`: `id`（`^\d{4}-\d{2}-\d{2}(-[a-z0-9]+)?$`。撮影日。同じ日に別の走行と分かれば `-b` などを付ける）・`split`（`train` / `val` / `test`）
  - `[[clip]]`: `id`（= `dataset/raw/self/` のフォルダ名。`^\d{8}_[a-z0-9][a-z0-9-]*$`）・`file`（フォルダの中の映像の名前。`/`・`\`・先頭の `.` を含まない）・`sha256`（64 桁の 16 進）・`drive`・`camera`・`time_of_day`（`day` / `dusk` / `night`）・`area`（`道東` / `道北` / `道央` / `道南` のどれか。これより細かい地域・距離標・集落名を書かない）・`deer`（鹿のいる区間 `{start = 秒, end = 秒}` の配列。`end` を省くと映像の終わりまで。鹿なしは空の配列）
  - **時刻を残さない**: `id` の日付より後ろと `file` に 4 桁以上の続いた数字（時・分・秒の形）を書かない → エラー。ドラレコの元の名前は改名して置く（C4）
  - クリップの `id` の日付が、`drive` の日付かその翌日（0 時を跨ぐ夜の走行）でない → エラー（C3）
  - 知らない `drive` / `camera`・`id` の重複・**元の `sha256` の重複**（同じ映像の 2 行。C2）・知らないキー・値・日付として正しくない日付 → エラー（キー名とクリップ名つき）
  - `[settings]`: `deer_every_s`（鹿の区間を書き出す間隔。既定 0.2 秒）・`no_deer_every_s`（鹿なしの区間。既定 1.0 秒）・`margin_s`（鹿の区間の前後で、鹿なしにも数えない余白。既定 5.0 秒）。どれも正の数
  - 違反があれば何も書かない
- R2: 元の映像の照合
  - 元の映像は `<raw>/<clip.id>/<clip.file>`。実体のパスが `<raw>` の中でない・シンボリックリンク・無い → エラー
  - SHA-256 を計り、一覧の `sha256` と `<file>.sha256`（1 行目の先頭 64 桁）の**両方**と同じであること。違えば、そのクリップでエラー（何も書かない）。元のファイルは開いて読むだけ
  - 映像の大きさがカメラの `size` と違う → エラー（矩形がずれるため）
- R3: 区間と書き出すフレーム
  - fps とフレーム数は映像から読む。フレーム `i` の時刻は `i / fps`。秒からフレームへは切り上げ（`ceil(t × fps)`）
  - 鹿の区間 `[start, end)`（`end` が無ければ終わりまで、映像の長さを超えれば終わりで切る）に入るフレームは「鹿あり」。鹿の区間の前後 `margin_s` 秒（区間の外側。0 秒より前は 0 で切る）に入るフレームは「除外」（書き出さない）。2 つの区間の間が余白 2 つ分より狭ければ、間はすべて除外。それ以外は「鹿なし」
  - 区間の `start` が映像の長さ以上・`end <= start`・`start` が負・区間の重なり → エラー
  - 書き出すのは、鹿ありはその区間の先頭から `every(deer_every_s)` フレームおき、鹿なしは各連続区間の先頭から `every(no_deer_every_s)` フレームおき。`every(s) = max(1, floor(s × fps + 0.5))`（0.5 は切り上げ。Python の `round` の偶数丸めを使わない）
  - 映像は先頭から順に読む（飛ばし読みの位置ずれを避ける）。書き出すはずのフレームが読めずに終わったら（opencv のフレーム数は推定のことがある）、そのクリップでエラー
- R4: 匿名化（フレームごと。JPEG に書く前）
  - 焼き込み: カメラの `overlay_masks` の矩形を黒（0）で塗りつぶす。**切り取らない**（16:9 と画面の中心を保つ。L0 は 640×480 に余白なしで縮め、合成はカメラの中心を背景に合わせるため）
  - 顔・ナンバー: 塗りつぶした後のフレームで、COCO の検出器（`edge/detector/models/yolo26n.pt`、入力の長辺 1280 px、確信度 0.15 以上）が出した `person` の箱は全体を、`car` / `motorcycle` / `bus` / `truck` の箱は下半分（ナンバーの位置）を、それぞれ 10% 広げてからモザイクにする。モザイクの 1 マスは `max(12, min(幅, 高さ) // 4)` px（読めない粗さ）
  - 重みは、ファイルがあり、SHA-256 が COCO の `yolo26n.pt`（Ultralytics v8.4.0 の配布物、`9b09cc8b…`）と同じであること。無ければエラー（ダウンロードしない）。検出器は結果のファイルを書かない（`save=False`）・利用状況を送らない（オフライン）
  - 検出器は差し替えられる（テストは偽物）。使った重みの名前と SHA-256、確信度、入力の大きさ、クラスを manifest に書き、ぼかした箱をクラスつきでフレームごとに書く（箱は画素の矩形だけで、個人の情報を含まない。鹿を誤って人と検出してぼかしていないか、ラベル付けのときに照らし合わせるため。W3）
  - 音声は書き出さない（フレームの JPEG だけを書くので、元の映像の音声・メタデータ・GPS のトラックは出力に入らない）
  - **確かめ**（1 秒おきのフレームで。書き出すかどうかに関係なく。「明るい縁」= 画素の平均 > 180 かつ横と縦の差の和 > 60。5 本の実データで閾値を確かめた）:
    1. 陽性対照: 塗る前の矩形の中で、50% 以上のフレームで続く明るい縁の画素が `overlay_min_pixels` 以上あること。少なければエラー（矩形の位置違い・暗い色の焼き込みを、何も見つけずに通さない。C1）
    2. 塗った後、画面全体で 50% 以上のフレームで続く明るい縁が矩形の外に 50 画素を超えて残れば エラー（ほかの場所の焼き込み・ロゴ）
    3. 塗った後、矩形を 60 px 広げた帯（矩形の中を除く）で、**5% 以上のフレームで明るい縁になる画素が 1 つでもあれば** エラー（毎秒変わる GPS の下の桁・秒が矩形からはみ出している。続く画素だけを数えると見逃す。C1）。実データでは正しい矩形で 0、文字を切る矩形で 277〜871 画素
    - 昼に長く停まって標識などが帯に入ると 3 でエラーになりうる。そのときは矩形を広げて回し直す（エラーのまま通さない。I6）
    - 3 つの数を manifest に書く
- R5: 書き出し
  - 置き場所: `--raw` の実体は `dataset/raw/` の下、`--out` の実体は `dataset/private/` の下のフォルダ（どちらも Git の対象外）。外ならエラーで何も作らない（W1）
  - 同時の実行: `<out>/.ingest.lock` を `mkdir` で作る。既にあればエラー（並走のセッションが同じ manifest を書き合わない。止まった実行の鍵は手で消す）。終わったら消す（W4）
  - `<out>/frames/<clip.id>/<clip.id>_f<フレーム番号 6 桁>.jpg`（品質 95、EXIF・XMP・ICC なし）。書く前に、JPEG の SOS より前のマーカーが**許したもの（APP0（JFIF）・DQT・SOF・DHT・DRI）だけ**であることを確かめる。それ以外（APP1 = EXIF・XMP、APP2 = ICC、APP13、APP14、COM など）があれば、そのクリップでエラー（W5）
  - クリップごとに一時フォルダ（`<out>/frames/.tmp-<clip.id>/`）に書いてから名前を付ける。途中のエラーでは一時フォルダを消し、manifest を変えない。前の実行が残した一時フォルダは、始める前に消す
- R6: manifest（`<out>/manifest.json`）
  - 全体: `version`・`license: "self"`・`allowed_use: ["train", "eval"]`・`distribution: "not_allowed"`（ぼかしを人が確かめるまで）・`blur_reviewed: false`・`drives`（`id` → `split`）・`clips`・`files`・`sources`（クリップ → `{license: "self", camera, time_of_day, area}`。`dataset-train` の素材の manifest の `sources[video].license` に寄せる）
  - `clips[id]`: `fixed`（元の `sha256`・`file`・`drive`・`split`。変えられないもの）・`redo`（カメラ・矩形・陽性対照・時間帯・地域・区間・間引き・検出器の名前と SHA-256 と確信度と入力の大きさとクラス。変えたら `--redo` で作り直すもの）・`drive`・`split`・`camera`・`time_of_day`・`area`・`sha256`・`fps`・`frame_count`・`size`・`overlay_masks`・焼き込みの画素数（塗る前の中・塗った後の外・まわり）・ぼかした箱の数・区間（開始と終わりのフレームと秒、鹿の有無）・間引きの間隔（フレーム）・書いた枚数
  - `files[]`: `image`（`frames/…` の相対パス）・`label`（`null`。ラベル付けは後続）・`video`（クリップの id）・`drive`・**`group`（`self:<drive>`。学習と評価を分ける単位は走行。W7）**・`split`・`frame`・`t`（秒）・`deer`（真偽）・`uses`・`sha256`（JPEG）・`blur_boxes`（`{cls, box}` の配列）
  - `uses`: 鹿あり → `["label"]`（ラベルを付けてから学習・評価に使う）。鹿なしで分割が `train` → `["synth_background", "negative"]`。鹿なしで `val` / `test` → `["fp_eval"]`。**合成の背景は `train` の走行からだけ**（評価の走行の背景が合成画像を通って学習に入らないように）
  - **書かないもの**: 緯度経度・速度・焼き込みの日時・元のファイルの作成時刻・機種・元のファイル名（フォルダ名と `file` は一覧に書いたもの）・絶対パス
  - JSON は一時ファイルに書いてから置き換える。2 回目は既存の manifest に足す（下の R7）
- R7: 追加と分割の固定（2 回目に同じ手順で足すため）
  - 一覧のクリップのうち、manifest にあって `fixed` と `redo` が同じものは飛ばす（「済み」と表示）
  - **`fixed`（元の映像・ファイル名・走行・分割）が違う → 常にエラー**（`--redo` でも。既に学習に使ったかもしれないフレームが別の分割に移ると漏れになる。C2）
  - `redo` だけが違う → エラー（`--redo <clip.id>` を付けたときだけ、そのクリップのフレームを消して作り直す）
  - **manifest にある走行の分割を変える → エラー**。変えるときは manifest とフレームを手で消して全部作り直す（README に書く）
  - 新しいクリップの元の SHA-256 が、manifest の別のクリップと同じ → エラー（C2）
  - manifest に無いクリップの `frames/<id>/` がある（manifest を消した・改名の後に落ちた）→ エラー（`--redo` で作り直す。W4）
  - 一覧から消したクリップは manifest に残す（走行の分割の固定は続く）。「一覧に無いが manifest に残す」と表示する（W4）
  - 終わりに、`test` の走行で鹿ありのクリップの数を表示する。0 なら「テスト専用の鹿の走行がまだ無い（2026-11-07 の分で 1 本以上を `test` にする）」と表示する（エラーにはしない）

## ユースケース

### UC-1: 一覧を読む（R1）

- **Given**: `self_footage.toml`
- **When**: `ingest`
- **Then**: カメラ・走行・クリップ・設定が検証され、違反はキー名とクリップ名つきでエラー、何も書かない

### UC-2: 元の映像を照合する（R2）

- **Given**: 元の映像と `.sha256`
- **When**: `ingest`
- **Then**: SHA-256 が一覧とサイドカーの両方と合うクリップだけが処理される。違えばエラーで、元のファイルは変わらない

### UC-3: 区間と書き出すフレームを決める（R3）

- **Given**: fps・フレーム数・鹿の区間・設定
- **When**: 区間を計算する
- **Then**: 鹿あり・除外・鹿なしが分かれ、決まった間隔のフレーム番号が出る

### UC-4: 匿名化する（R4）

- **Given**: 焼き込みのある偽のフレームと、決まった箱を返す偽の検出器
- **When**: フレームを処理する
- **Then**: 矩形が黒になり、人の箱の全体と車の箱の下半分がモザイクになり、焼き込みの残りの検査が通る。矩形の外に焼き込みが残る一覧ではエラー

### UC-5: 書き出しと manifest（R5・R6）

- **Given**: 処理したフレーム
- **When**: 書き出す
- **Then**: JPEG にメタデータが無く、manifest に用途・分割・SHA-256 が書かれ、位置・時刻・機種・絶対パスが無い

### UC-6: 2 回目に足す（R7）

- **Given**: 1 回目の manifest と、行を足した一覧
- **When**: `ingest`
- **Then**: 新しいクリップだけが処理され、済みのクリップは飛ばされ、走行の分割の変更はエラー

## 状態パターン

### S-1: 途中で失敗した

- **Given**: 3 本目のクリップの照合か確かめでエラー → **Then**: そのクリップの一時フォルダが消え、manifest は 2 本目までの内容で残る（済みのクリップは次の実行で飛ばされる）

### S-2: テストの鹿の走行がまだ無い

- **Given**: 1 回目の 5 本（`test` の走行が無い） → **Then**: 処理は成功し、「テスト専用の鹿の走行がまだ無い」と表示する
