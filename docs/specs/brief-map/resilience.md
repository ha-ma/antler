# 障害耐性: brief-map（A-2 出発前ブリーフィング・その日のルートとゾーン）

方針: **回線が無くてもルートと鹿ゾーンは出す。** api はルートを同梱のデータから計算するので外部に依存しない。
画面で外部に依存するのは地図の背景（OpenFreeMap）だけで、出せなければ背景なしで同じ SVG を出す（ch9 ① d、デモの縮退）。
読み出しだけで書き込みが無いので、再試行は何度しても安全。

## Concurrency / Idempotency

| 対象                      | 並行実行されうるか               | 二重実行されうるか          | 冪等性要件                                 | 実装方針                                                                                   |
| ------------------------- | -------------------------------- | --------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| GET /api/trips/:id/day/:n | 同じ旅を別の端末から同時に読む   | 再読み込み・再試行          | 不要（読み出しだけ。同じ入力から同じ結果） | 毎回 DB を読み、純粋関数で計算する。キャッシュも書き込みもしない                           |
| 地図の初期化              | 日の切り替えで地図を作り直しうる | React の StrictMode で 2 回 | 片付けを必ずする                           | 地図はページで 1 つ作り、日の切り替えではルートと範囲だけ変える。外すときに `map.remove()` |
| routes.json の取り直し    | N/A: 手で 1 回走らせる           | 走らせ直しうる              | 同じ OSRM の版なら同じファイル             | 組を決まった順に並べて書く（差分が読める）                                                 |

## トランザクション境界

### 操作: GET /api/trips/:id/day/:n

1. パスの検証（DB の前）
2. 旅を 1 回読む（トランザクション不要。読み出し 1 回）
3. 純粋関数で DayPlan を作る（DB・外部に触れない）
4. 返す

- 補償処理: N/A: 書き込みが無い
