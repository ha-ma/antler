# 変更指示 2026-11-06（3 回目）：A の運転の音と観光の表示の頻度

> **この指示で変わるのは A の運転（`apps/sim/src/features/drive/` の audio・chat・おすすめのカード）と、音源（`apps/sim/public/audio/`）・`CREDITS.md` だけ。** 3 状態の色・形・音（alert-ui）、AlertFlag・Capture・TripPlan の形、api、B は変えない。
> feature は drive-sound-tourism（`docs/specs/drive-sound-tourism/functional.md`）。前の feature drive-audio-chat の R4・R5・R6・R8・R9・R12 と、drive-tourism の T11・T12 を変える（各仕様に注記）。
> 同じ日の 3 回目の指摘のうち「鹿にぶつかったときに画面がまわりから暗くなる」演出は drive-crash-spot のセッション。結果の画面は result-screens のセッション。原本（Claude Docs）が直るまで、この文書と各節が指す `docs/specs/` が正。

## 1. ユーザーの指摘（原文）

1. 「ライセンス的に問題のない音楽をBGMとしたい。現在の合成音声は違和感がある。」
2. 「ブレーキ音がない」
3. 「旅の観光コンテンツの表示が、あまり表示されずにつまらない気がする。表示頻度を高くしたい」
4. 「メッセージが入った時の通知音がない」
5. 「鹿にぶつかったときに、ぶつかった時の衝撃音を出して、…」（衝撃音だけがこの feature。暗くなる演出は drive-crash-spot）

## 2. 原因

- **通知音**: 前の決まり（R8）は「緑のときだけ鳴らす」。ステージの走り出しで道のりが飛ぶので出る行が少なく、反応の行はゾーンに入って 2.5 秒後＝琥珀の中で出る。出る行のほとんどが琥珀なので鳴らなかった
- **ブレーキ音**: 鳴ってはいたが聞き分けられなかった。雑音の乱数が丸まりで短い周期に縮退していた・帯域がラジオの雑音と同じ・小さい・鳴きが笛のような正弦波
- **観光の表示**: 見本の会話は 20 km ごと、おすすめのカードは 1 ステージ 1 回。走り出しがゾーンの 1 km 手前になると（drive-crash-spot）ほぼ出ない

## 3. 推奨で決めたこと（CLAUDE.md の方針。PR にも書く）

### 3.1 BGM（指摘 1）

- OpenGameArt の **CC0 の 3 曲**（Calm Track / pmiller、Slow Stride / isaiah658、Morning Sky / Centurion_of_war）。CC BY-SA・NC・ND・独自ライセンスは使わない
- −18 LUFS・モノラル 64 kbps の mp3。1 曲 2.5 MB 以下・合計 5 MB 以下（テストで守る。いまは合計約 4.1 MB）
- 「出発」の操作の後に `<audio>` で読み込んで流す（初回読込 3 秒・JS の上限に入らない。曲全体を展開しない）
- 最初の曲はシードで決め、終われば次の曲。赤で大きさ 0（曲は止めない）、琥珀で 0.6 倍、消音・BGM OFF・音量 0・終わり・タブを隠すで一時停止。開発中の既定の無音（`VITE_GAME_AUDIO`）は変えない
- ラジオのまね（帯域と常時の雑音）と合成の曲（`radio-score.ts`）をやめた
- 出所は `CREDITS.md`、ライセンス本文は `apps/sim/public/audio/CC0-1.0.txt`

### 3.2 ブレーキ音（指摘 2）

- こすれの雑音をシード付きの乱数で作り直し、帯域を 900 Hz に下げ、大きくした
- 鳴きは CC0 の録音（BigSoundBank #0500 Tire squeal / Joseph SARDIN）を 1.1 秒ごとに鳴らす。Space の全力ブレーキ（強さ 0.7 以上）・20 km/h 以上。ABS の路面（雪・凍結・濡れ）では 0.6 倍で 14 Hz の断続

### 3.3 通知音（指摘 4）

- 緑と琥珀で鳴らす。琥珀は 1 音・0.6 倍（ゾーンのチャイムの 2 音と聞き分ける）、ゾーンに入って 2 秒は鳴らさない。**赤の間は鳴らさない**（変えない）

### 3.4 衝突の音（指摘 5 の一部）

- エンジンの合図 `collided` で 1 回。CC0 の録音（OpenGameArt Crash Collision / qubodup）＋自作の低いドスン。運転の音の消音・音量に従う（鹿の警告の音とは別）。約 0.6 秒

### 3.5 観光の表示の頻度（指摘 3）

- 会話（右上）: ゾーンの外で、最後の行から**実時間 15 秒**あいたら観光の行を 1 行足す（飛ばした楽しみの行、無ければ楽しみの補いの行を順に）。ゾーンの中・入口の 300 m 手前・赤の間は足さない
- おすすめのカード（右下）: 1 ステージ 1 回をやめ、ゾーンの外ならいつでも出す（ゾーンを出た後・赤の後は 4 秒あける）。**12 秒ごとに次の楽しみに入れ替える**
- 実時間は「経過 ÷ 再生速度」（タイムラプスで流れ込まない）

### 3.6 要件との違い

| 要件・仕様             | 前                               | 変更後                                           | 理由         |
| ---------------------- | -------------------------------- | ------------------------------------------------ | ------------ |
| drive-audio-chat R5    | 自作の合成の曲（ラジオの帯域）   | CC0 の 3 曲                                      | 指摘 1       |
| drive-audio-chat R8    | 通知音は緑だけ                   | 緑と琥珀（琥珀は 1 音・0.6 倍）。赤は鳴らさない  | 指摘 4       |
| drive-audio-chat R12   | 道のりの行と反応だけ             | ゾーンの外で 15 秒あいたら観光の行を足す         | 指摘 3       |
| drive-tourism T11・T12 | 1 ステージ 1 回・1 つの楽しみ    | ゾーンの外ならいつでも・12 秒ごとに入れ替え      | 指摘 3       |
| CREDITS「運転の音」    | 音声ファイル・既存の曲を使わない | CC0 の曲と効果音を使う（エンジン・通知音は自作） | 指摘 1・2・5 |

凍結 API（`packages/schema`・`packages/alert-ui`）は変えていない。
