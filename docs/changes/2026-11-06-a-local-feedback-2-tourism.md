## 1. ユーザーの指摘（原文）

1. 「運転中に出てくる会話を、選択した観光コンテンツの内容と画像が出てきた会話にしたい。右上あたり」
2. 「危険ゾーンに到着する前に、観光コンテンツのおすすめの内容が表示される等（メッセージ欄とは別で）、旅行が楽しくなるような試みをしたい。表示箇所はウィンドウの右下あたり」

## 2. 推奨で決めた解釈（CLAUDE.md の方針。PR にも書く）

### 2.1 会話を観光の話に（指摘 1）

- 車内の会話の話の行（出発の行以外）の **3 分の 2 を「楽しみの話」**にする（話の行を順に数えて i mod 3 が 0・1 の行）。残りは今までの天気・光・景色・おやつ・音楽
- 話題にする楽しみ: **その日のこれからの楽しみ**（A-1 で選んだ立ち寄り）を順に回す。その日の楽しみを過ぎたら、いちばん最近のものの振り返りと後の日の楽しみ。その日に楽しみが無ければ後の日の楽しみ（最大 3 件）
- 同じ楽しみが続いても文が変わるよう、切り口を回す: 期待 → 見どころ → 楽しみ方のこつ（済んだものは振り返り）
- Claude には楽しみの名前・拠点の地名・時間帯・所要の区分・切り口・今日か後の日かを渡す。**材料に無い施設名・店名・料金・時刻を作らせない**。文の検証（数字・鹿の語・簡体字）は今までどおり
- 吹き出しに**楽しみの写真（64 × 48）と出典「写真: 撮影者 / ライセンス」**（A-1 と同じ Wikimedia Commons の写真）。出典は HUD なのでリンクにしない（リンクは A-1 のカードと `CREDITS.md`）
- 置き場所は**右上**（右の列の上から積む）。写真で 1 行が高くなるので、見える行は**新しい 3 行**（前は 4 行）
- 旅の無い見本の運転・api が使えないときの見本の会話も、同じ数え方で楽しみの話を入れる（その日の楽しみ、無ければ到着地の楽しみのうち旅の月に合うもの）
- 赤の間に行を待たせる・通知音を鳴らさない・減光する決まりは変えない

### 2.2 鹿ゾーンの前のおすすめ（指摘 2）

- 会話とは別のカード「この先のおすすめ」を**右下（音量の操作の上）**に出す。中身: 写真・楽しみの名前・一言・所要の目安・（拠点が到着地なら）到着地の時刻・写真の出典
- 出しどき: **1 つのステージに 1 回**。ステージの始まり（ゾーンの入口の 5 km 手前）から、そのステージで最初にゾーンに入る・赤になるまで。ステージのクリアの帯（2 秒）が消えてから出す。同じステージでゾーンの外に戻っても出し直さない（ゾーンの中・赤の間は前を見てほしいため）
- 出す楽しみ: **今の位置より先のその日の楽しみ**のうちいちばん近いもの。無ければ到着地の楽しみ（旅の月に合うもの）をステージごとに回す
- 一言に鹿の語が入る楽しみは一言を出さない（赤の警告と取り違えさせない）
- 操作要素なし・点滅なし・読み上げの領域にしない（アラートの読み上げと重ねない）。画面の高さが 760 px 以下ではカードの写真を出さない

### 2.3 要件との違い

| 要件 | 書いてあること                            | 変更後                                                            | 理由                                           |

| A3-5 | 「つぎの楽しみ」のカードは右上            | 会話を右上、おすすめを右下                                        | この指摘（会話は右上、おすすめは右下）         |

### 2.4 データ

- 会話の束の行に `pleasure`（楽しみの id か null）を足した。保存の表は変えない（束は JSON の列）ので **`SCHEMA_VERSION` は据え置き**。保存の鍵の版を `chat:v2` に上げた（前に保存した束は読まれず、次に開いたときに作り直す）
- 凍結 API（`packages/schema`・`packages/alert-ui`）は変えていない

## 3. 残したこと（Deferred）

- 楽しみの話の多さ（3 分の 2）と、おすすめを出し始める位置（ステージの始まり）は、実機で見て決める（ユーザー、Day 6）
- 途中の立ち寄りの到着の目安は出さない（場面が移動ごとの地点の時刻を持たないため。A-4 の組み込みで）
