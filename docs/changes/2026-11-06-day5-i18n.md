## 2. 推奨で決めたこと（PR にも書く）

1. 文言の表は **TS のまま**（ch5 は「JSON 辞書」）。型で 4 言語の欠けを止められ、表の数が多く移し替えの割に得るものが無い。検査は TS の値を読むので JSON と同じ効き目
2. 検査の置き場所は共通のパッケージ＋workspace ごとのテスト（自動の収集）。名前の規則に合わない表は相対 import で登録する
3. 直書きの検査は「行の形」でなく「文字」で見る。`ci_arch_check.py` は Amptech 由来で取り込み直しで上書きされるので、規則は antler の `dispatch_local_rules.py` に置き、CI は dispatcher 越しに当てる
4. zh は繁体字（zh-TW）。日本の新字体（発・駅・図など）と簡体字の一覧で落とす。zh と ja が同じ漢字の語（地名）は写しにしない
5. ブラウザの言語の正は、A は `initialLang`（既定 ja）、B は `resolveLang`（凍結。既定 en）のまま
6. エラー画面は 4 言語を並べる（描画が壊れたときは旅の言語を読めない）
