## 10. 開発計画・受け入れ基準・リポジトリ

> 出典: Claude Docs「EZO ROAD システム要件定義書 v1」https://claude.ai/artifact/Jr6zYHcjdSy5xEd1WaG7v8 （2026-11-03 エクスポート）。本文は原文のまま。変更は原文側で行い、再エクスポートする。


1 週間、2 名。A と B は并行するが、`@ezoroad/alert-ui` と Capture スキーマを Day 1 に固めて両者の接点を先に作る。第 9 章の判断は Day 1 の午前までにもらう。

| Day | A（3D シミュレーション） | B（車載検知） | 共通 | ゲート |
| --- | --- | --- | --- | --- |
| 1 | monorepo、デザイントークン→CSS/TS、A-1 フォームとしおり生成 | Mac Mini セットアップ、カメラ取込、YOLOv8 CoreML で deer 推論が動く | `alert-ui` の 3状態、Capture / AlertFlag スキーマ、鹿ゾーン GeoJSON 初版 | 第 9 章の判断確定 |
| 2 | A-2（地図＋ゾーン＋トグル）、3D シーンの骨格（道路・車内・カメラ追従・HUD 固定） | WebSocket サーバー、Wi-Fi AP、PWA の B-0/B-1 | 音源 3 種と読み上げ 4 言語 | PC で車が走る。スマホがフラグを受ける |
| 3 | 車両力学、ゾーン進入・タイムラプス、鹿モデル組込と出現 5 パターン | B-2/B-3、判定ロジック（2 フレーム、1.5 秒）、遅延計測 | 車内スマホに `alert-ui` を表示 | A-5 で赤が出て音が鳴る。B で実機検知→通知 < 1 秒 |
| 4 | A-4 イベント、A-6 喪失、A-7 記録 URL、キャプチャ保存 | 調査走行（土夕）で実データ収集。検知フレーム保存 | 同意 UI、データセット書き出し | A が最初から最後まで通る |
| 5 | スマホ横画面、多言語、パフォーマンス（60/30 fps） | 調査走行（日午前）、誤検知・見逃しの記録、閾値調整 | 学習スクリプト（A キャプチャ＋実写→再学習→CoreML） | データループが 1 周回る |
| 6 | バグ修正、写真差し替え、統計カードの数字確認 | 車載の振動・熱・再接続テスト | README、CREDITS、ライセンス確認 | 受け入れ基準をすべて満たす |
| 7 | 3 分デモ動画の撮影（A 画面） | 3 分デモ動画の撮影（実機） | 動画編集、提出 | 提出 |

**スコープ外（MVP ではやらない）**：ログイン・アカウント、決済、レンタカー事業者向けダッシュボード、BLE 実装、鹿以外の動物、道央エリアの 3D シーン（しおり・地図は対応、3D は道東のみ）、ネイティブアプリ。

**受け入れ基準**

- [ ] A-1 で 10 件まで選び重さを付け、しおりが即時更新される
- [ ] A-3 で PC 60 fps、スマホ横 30 fps。HUD はカメラを動かしても固定
- [ ] 鹿ゾーン進入で琥珀＋チャイム、鹿検知で赤＋ビープ＋読み上げ。アラート OFF では一切出ない
- [ ] 衝突で A-6（取り消し線と 4 指標）、完走で A-7（URL が別ブラウザで開く）
- [ ] A-6 の「アラート ON でやり直す」が同じシードで再生される
- [ ] B 実機で、鹿の写真をカメラに見せてからスマホが赤になるまで 1,000 ms 未満（ログで証明）
- [ ] A の車内スマホと B の PWA が同じ `AlertState` コンポーネントを使っている（コードで確認）
- [ ] Capture が A/B 両方から同じスキーマで保存され、同意のないものはアップロードされない
- [ ] 統計の数字が設定ファイルにあり、出典が画面に表示される
- [ ] 全アセットのライセンスが `CREDITS.md` にあり、公開リポジトリ要件を満たす

**リポジトリ構成（提案）**

```markdown
ezo-road/
  apps/
    sim/            # A: Vite + React + R3F
    pwa/            # B: スマホ PWA
    api/            # A API（Hono）
  packages/
    alert-ui/       # 3状態コンポーネント・音源・トークン
    schema/         # TripPlan / AlertFlag / Capture の型と JSON Schema
    zones/          # 鹿ゾーン GeoJSON と生成スクリプト
  edge/
    detector/       # B: Mac Mini 上の jev パイプライン（Python）
  dataset/          # 匿名キャプチャと学習スクリプト
  design/           # Claude Design のエクスポート、tokens.json のコピー
  docs/             # この要件定義書（Markdown エクスポート）、判断記録
```
