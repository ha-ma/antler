## Warning

| #   | 指摘                                                                            | 決定                                                                                                                                                           |
| --- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| W1  | `Host` の検査が無く DNS rebinding で一覧が読める                                | `Host` のホスト名を IP リテラル・`localhost`・`ezoroad.local` に限る（421）。AUTH-13                                                                           |

| W4  | 画像の検査の穴（EOI の後ろの余り・JFXX・サムネイル・巨大な寸法）                | 末尾の余りを拒否、APP0 は JFIF 1 つ・サムネイル 0×0、寸法 16〜2048（A3、IMG-1f）                                                                               |
| W5  | id の長さ・大文字小文字・multipart の重複・冪等のハッシュの定義・バイト数の上限 | id 40 文字まで、key は小文字、multipart の型と重複を 400、ハッシュはキー辞書順の JSON + 画像の sha、`CAPTURES_MAX_BYTES`（A4・A5・A9）                         |
| W6  | 保持期間・取り消し・429 の扱い                                                  | edge の保持期間 24 時間。api の保持と取り消しは Deferred（担当・期日・暫定挙動つき）。429 は `Retry-After` を待ち、それでも 429 なら「混み合っています」（P3） |

## Info

時計の巻き戻し（REC-1i）、長さ 0 の JSON（STO-1k）、一覧はメモリの索引から返す（E5）、`wrap` の最後の 1 枚は offer されない場合がある（E6）、「5 秒に 1 枚」を 2 秒に直した（E2）、見出しを「未送信の検知フレーム N 件」にした（P2）。

## 問題なしと判定された点

id の正規表現によるパスの検査、クライアントの `image` を使わないこと、strict スキーマ、api に読み出し・削除の口を作らないこと、`SegmentProvider` が座標を受け取らないこと、キューが溢れたら捨てて数えること。
