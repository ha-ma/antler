# i18n: ネイティブの確認が要る zh-TW・ko の文言（2026-11-06）

docs/specs/i18n/functional.md R9 と Deferred「zh-TW・ko の文言のネイティブ確認（担当=ユーザー、期日 2026-11-08）」の一覧。
この cycle で Claude が新しく書いた zh-TW（繁体字）・ko の文だけを挙げる。機械の検査（`@antler/i18n-check`）は
文字種・簡体字・日本の新字体・欠け・写しまでで、**言い回しの自然さと用語の統一は見ていない**。

確認のしかた: 各ファイルの `zh:` と `ko:` の節を読み、直すところはそのファイルを直す（表の形は変えない。
`{n}`・`{of}`・`{km}` などの差し込みの名前は 4 言語でそろえる。そろわないと `npm test` が落ちる）。

## 機械の検査で見つけて直したもの

- HUD・季節・天候・路面・ナビ・エラー画面は ja しか無かった（4 言語にした）
- 旅を読み込む前の「旅を読み込んでいます」「旅が見つかりません」、A-6 の読み込み前・失敗が ja 固定だった（ブラウザの言語にした）
- `HTML_LANG`（`zh-Hant`）を文言の表に置いていた pwa の表は、文言でないので表の外（`AppErrorBoundary.tsx`）に移した
