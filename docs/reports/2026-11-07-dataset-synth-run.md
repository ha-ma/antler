## 仕様からのずれ

- 書いた枚数は 469 で、「600 前後」に届かなかった。試しの run（`min_contrast = 8`）では書ける割合が約 45% だったが、10 に上げて薄い鹿を捨てたため 36% になった。追加の run はしない（推奨で決定）。比べるのに足りなければ、dataset-train の更新で別のシード・別の run 名で足す
- 暗い背景（路面の帯が暗いフレーム）の鹿はほぼ `dark` で捨てられる。夜の暗い場面の鹿は、この run にはほとんど入っていない（見えない鹿に箱を付けないための作り。暗い場面の鹿は実写のラベル付けで補う）
