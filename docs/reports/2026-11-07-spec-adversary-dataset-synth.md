## Critical

### C1. R6 の合成のしかたで、どの鹿にも見分けられる跡が残る

- 該当: R6 の「鹿の層（RGB とアルファ）を `blur_px` の σ でぼかす」と「鹿のアルファが 0 でない画素に σ `noise` のガウスのノイズを足す」
- Blender で背景を透明にして書いた PNG は straight alpha で、透明な画素の RGB は 0。RGB とアルファを別々にぼかすと、縁で 0 の RGB が混ざり、どの鹿にも暗い縁取りが付く
- ノイズを鹿の画素だけに足すと、背景（q95 の JPEG を開いて再圧縮）と鹿（きれいな描画）でノイズと圧縮の性質が違う。YOLO は鹿の形ではなく描画の跡を覚え、実写の夜の鹿では効かない
- 直し方: ぼかしの前に premultiply し、ぼかした後に戻す。ノイズは画面全体に同じ σ で足す。COMP-5a に「縁の画素が鹿の内側と背景の両方より暗くならない」を足す

### C2. 受け入れ基準が落ちる形になっていない（見えない鹿に箱が付く事故を止めるものが無い）

- 該当: `[accept]` の 4 つの値、Questions、受け入れ基準
- 4 つの値が Questions で決まっていない。明るさの確かめに合格の線が無い。実物の描画を目で見る項目が無い（テストは全部偽の描画）
- `min_contrast` が差の絶対値の平均なら、ノイズ（σ 3 なら平均 約 2.4）だけで暗い鹿も通る
- L0 には `FRAME = (640, 480)` に縮めて渡る（縦 ×0.44）。値を 1080p の画素で決めると L0 では半分以下
- 直し方: 4 つの値を L0 の入力の画素で決める。`min_contrast` はノイズの前・ぼかしの後で測る。出力からシード付きで 30〜50 枚を選んで箱を描いた一覧を `dataset/private/` に作り、目で見る（見えない鹿に箱・箱の無い鹿・浮いた鹿・暗い縁）。明るさに合格の線を決める（例: 距離の帯ごとの中央値が路面の帯の 0.5〜2 倍）

### C3. カメラと照明が、実際の背景と結び付いていない

- 該当: Questions の「カメラ」（2026-09-07 の朝で測った値）、`[headlight]`、R3 の「足を路面に置く」
- 背景は 2026-11-06 の夜。カメラの値は 2 か月前の別の走行で測った（車・取り付けが違いうる）。`pitch_deg` が 1° ずれると 50 m 先の足は約 24 px ずれる
- ドラレコの水平の画角は 100° を超えることが多く、69° は狭い。歪みの無視は横 ±6 m で特にずれる
- ヘッドライトの強さが背景と無関係で、真っ暗な背景に明るい鹿が立つ。地面が無いので影も接地の陰りも無い
- 「夜の暗い中で明るく浮いた物 ＝ 鹿」を教える
- 直し方: 夜のクリップの地平線を測って朝の値と比べる。鹿の足の位置の背景の明るさと鹿の明るさの比が範囲外の鹿を捨てる。shadow catcher で影を入れる

### C4. 背景に箱の無い本物の鹿が入る見込みが「少ない」とは言えない

- 該当: Questions の「背景」、Deferred
- `synth_background` の 643 枚のうち 289 枚（45%）が鹿ありの 2 本から来ている。横断の映像では説明に無かった群れが見つかった実例がある。30 秒より前・150 秒より前は見ていない
- 学習が一番苦手な夜の暗い鹿を背景として教えることになる
- 直し方: 1 回目は鹿なしと言われた 2 本（354 枚）だけを背景にする。一覧に使うクリップを足す

## Warning

- W1: 焼き込みの矩形で切れた鹿が通る（R4 は中心だけ確かめる）。「黒い矩形の横に鹿」というドラレコにしか無い特徴を教える → 焼き込みに隠れた割合も `max_cut` に数えるか、射影の箱が矩形と重なる置き方を置き直す
- W2: 「1 頭でも採らなければ 1 枚を捨てる」で、書いた画像の距離・頭数の割合が計画とずれる → 距離の帯・頭数ごとに計画と書いた数を並べて表示・報告する
- W3: Python の射影と Blender のカメラを突き合わせていない（`sensor_fit`・pitch の符号・+Y の向き）→ `check` で決めた点に印を置いて描き、射影とのずれを確かめる。R5 に `sensor_fit = HORIZONTAL`
- W4: 目の反射を向き・距離に関係なく光らせている（後ろ向きの鹿にも光る点）→ 頭とカメラの角が一定以内のときだけ光らせるか、今回は発光をやめる
- W5: 今の `collect_yolo` は group を `yolo:{video}` で作り、`files[].group` を読まない → 漏れの検査に使うのは `files[].group`（`self:<drive>`）と R8 と Deferred に書く。背景の manifest を後で直したときに古い run を見つけるため、登録の時点で `footage_manifest_sha256` と背景がまだ `synth_background` かを確かめる、と Deferred に書く
