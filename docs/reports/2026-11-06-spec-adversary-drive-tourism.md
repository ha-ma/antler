# 敵対レビュー結果: drive-tourism（2026-11-06）

対象: docs/specs/drive-tourism/functional.md（spec_confirmed_at: cff9f43）。spec-adversary（opus）の返答を、メインセッションが保存した（エージェントは読み取り専用）。取り込みは functional.md の「spec-adversary の指摘と決定」の表。

## Critical

- C1. T11 の「5 km 手前」は、ステージの始まりが入口の 5 km 手前（`stages.ts` の STAGE_LEAD_M）なので「ステージの中でゾーンの外ならいつも」になる。まとめたステージではゾーンの合間に出入りを繰り返し、赤の後にすぐ出直す。ステージの始まりはちょうど 5.0 km で境界が決まらない → 出しどきを `stage.index` で決め、1 つのステージに 1 回、始まりから最初のゾーンの入口まで。ゾーンを出た後・赤の後に出し直さない

## Major

- M1. ステージの始まりで帯・会話の行・通知音・カードが同時に出る → カードは帯が消えてから（2 秒後）
- M2. T12 が通り過ぎた楽しみを「この先のおすすめ」に出し、会話の「さっきの」と食い違う → 今の位置より先の楽しみから選ぶ
- M3. 楽しみの季節（months）がどこでも使われていない → 到着地の楽しみなど自動で選ぶ候補を旅の月で絞る
- M4. 拠点がどの移動の始まり・終わりにも無い楽しみが leg 0 から done になりうる → その日の最後の移動まで ahead
- M5. 後の日の楽しみと今日の楽しみを Claude が区別できない → 材料に `when: 'today' | 'later'`
- M6. ko の助詞・en の冠詞が、差し込む名前で崩れる → 名前を独立させる言い回し
