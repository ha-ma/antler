## 仮採用（danger を大きな文字にして 3:1）の是非

WCAG 1.4.3 の例外としては適合（unit 32px / 19px 太字、副文 20px 太字、見出し 32px 太字）。ただし恒久策には勧めない:
ch5 の「4.5:1（確認済み）」は誤記で要件を緩めることになる、フォントのフォールバックで太字が効かないと崩れる、文字を足すたびに崩れうる。
本命は赤を少し暗くして 4.5:1 に届かせること（白との比で輝度 0.183 以下。#E2492C は約 0.211）。緑との明度差も同時に広がる。
ユーザーの確認までの暫定としては許容。
