# 配布できないデータ（`dataset/private/`）

`dataset/private/` は `.gitignore` 済みで、リポジトリに入れない。ここに置くデータは、学習データとして配れないもの。

## 参考写真: Yuki Fujita（2026-11-04 受け取り）

- 置き場所: `dataset/private/reference-photos/yuki-fujita-2026-11/`（8 枚、1477×1108、撮影情報は無い）
- 中身: エゾシカのオス・メス・夏毛の斑点が残る若い個体・群れ・遠くの小さな個体・顔の寄り。夕方の光が多い
- 利用条件（2026-11-06 にユーザーが更新。Osaki さんの写真と同じ扱い）:
  - このプロジェクトの中で**使ってよい**（学習にも使ってよい）
  - **二次利用・公開は不可**
  - クレジットの記載は不要
  - 2026-11-04 の初回の条件は「評価と 3D の参考だけ、クレジット要、学習データとしての配布は不可」だった
- 使ってよい用途:
  - **学習と評価**: B の鹿の検出（YOLO）。8 枚と少ないので、評価に残すか学習に入れるかは学習の cycle で決める
  - **3D の参考**: A の 3D の鹿の形・色・臀の白斑・姿勢の参考。AI 3D 生成の元にするときは、生成物を配る前に ch9 ③ の判断を見直す
- してはいけないこと:
  - リポジトリにコミットしない。公開の場所（PR・Issue・デモの配布物・報告書）に写真そのものや切り抜きを載せない
  - 写真を加工したものを第三者に渡さない
  - この写真で学習した重みを外に配るときは、AGPL の扱い（CREDITS.md の Ultralytics の行）と合わせて、先にユーザーに確かめる
- 別の機械（Mac mini）で使うときは、Git ではなく手でコピーする

判断は `docs/requirements/ch9-decisions.md` の ③ の行。
